# Hugging Face Model Trends

매일 Hugging Face에서 최근 공개됐거나 관심이 빠르게 커지는 AI 모델을 조사하고, 중복을 제거한 신규 후보를 최대 5개 한국어로 기록하는 아카이브입니다.

## 저장 구조

- 일일 보고서: `huggingface-model-trends/YYYY/MM/YYYY-MM-DD.md`
- 중복 제거 기준 파일: `huggingface-model-trends/introduced-models.md`

## 자동화 규칙

1. 실행 시 Asia/Seoul 기준 날짜를 사용합니다.
2. 조사 전에 반드시 `introduced-models.md`를 읽습니다.
3. 이전에 한 번이라도 소개된 모델과 같은 계열의 크기 변형, 양자화, GGUF/ONNX/MLX/FP8/NVFP4 포맷 변환, 경미한 미세조정, 직접 파생본은 다시 소개하지 않습니다.
4. 아키텍처·모달리티·핵심 학습법이 크게 달라진 명백한 차세대 모델만 1차 출처 확인 후 예외로 인정합니다.
5. 단순 다운로드 순위가 아니라 최근 공개/업데이트 시점, 트렌딩 상승세, 좋아요·다운로드 증가, 커뮤니티 반응, 기술적 독창성, 실무 활용성을 종합해 최대 5개를 선정합니다.
6. 각 사실은 최신 Hugging Face 모델 페이지, 개발사 공식 자료, 논문, 공식 저장소 등 1차 출처를 우선 확인합니다. 개발사 자체 벤치마크는 자체 평가임을 명시합니다.
7. 조건에 맞는 신규 후보가 5개보다 적으면 확인된 수만 기록합니다.
8. 일일 보고서 저장이 성공한 뒤에만 `introduced-models.md`에 당일 소개 계열을 추가합니다.
9. 이 자동화는 `skill-trends/` 경로를 수정하지 않습니다. 다른 예약 작업과 같은 저장소/브랜치를 사용하더라도 경로를 분리합니다.
10. 채팅에는 상세 보고서를 반복하지 않고 성공/실패 결과를 한 줄로만 출력합니다.

## 채팅 결과 형식

성공: `✅ YYYY-MM-DD Hugging Face 모델 트렌드 N개 GitHub 저장 완료 · Top Pick: <모델명>`

실패: `⚠️ YYYY-MM-DD Hugging Face 모델 트렌드 GitHub 저장 실패 · 원인: <짧은 이유>`

> 2026-08-25~2026-08-26의 보고서는 기존 ChatGPT 대화에서 마이그레이션했습니다. 당시 수치와 표현은 해당 보고 시점의 스냅샷입니다.
