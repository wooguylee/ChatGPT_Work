## 1. black-forest-labs/flux-3-action-base

- **개발사:** Black Forest Labs
- **분야/규모:** Robotics / World Action Model, **7B**
- **라이선스:** FLUX Kommunity License v1.0. 포함 Qwen3-VL-4B-Instruct text encoder는 Apache-2.0.
- **공식 GitHub:** https://github.com/black-forest-labs/flux-action
- **공식 문서:** https://docs.bfl.ai/

### 오늘 주목할 근거
조사 시점 Hugging Face Trending에 노출됐고 모델 페이지는 **1일 전 업데이트, 좋아요 75, Community 2, Space 1**을 표시했다. 다운로드는 Hugging Face에서 추적하지 않는다고 명시돼 있다.

### 기술적 차이
카메라 프레임, 로봇 상태, 자연어 지시를 함께 받아 **다음 action chunk를 다음 video frame과 공동 denoise**한다. video/text stream, shared action trunk, action heads를 사용한다. Qwen3-VL-4B-Instruct는 공유 text encoder로 포함된다. 새 로봇 embodiment에는 별도 action head 적응이 필요하다. 단순 VLM 질의응답보다 미래 장면 예측과 행동 생성을 하나의 world-action generation 문제로 묶은 점이 핵심이다.

### 활용 가능성과 제약
SO-101·DROID 정책과 연계하거나 새 로봇·시뮬레이터·게임용 action head를 fine-tune하는 용도에 적합하다. 일반 Ollama/LM Studio형 챗 모델이 아니라 LeRobot/robotics 파이프라인 쪽에 가깝고, 공개 base 자체는 완성형 범용 robot policy가 아니다. 실제 하드웨어에는 별도 motion/safety limit와 시뮬레이터 검증이 필요하다. 상업 배포 전 FLUX Kommunity License 조건 확인이 필요하다.

## 2. Contrastive-LM/CLM-v0.1-8B

- **개발사:** Contrastive-LM
- **분야:** Agent decision / Ranking / Verifier
- **구조:** frozen Qwen3-8B encoder + state/action projection heads
- **라이선스:** Apache-2.0
- **공식 GitHub:** https://github.com/Contrastive-LM/CLM

### 오늘 주목할 근거
조사 시점 Hugging Face Trending 두 번째 페이지에 있었고 **약 2시간 전 업데이트, 좋아요 134, Space 1**을 확인했다.

### 기술적 차이
자유 문장을 생성하지 않고 state와 action을 별도로 임베딩해 후보 action을 ranking한다. 작은 state head와 action head를 frozen Qwen3-8B encoder 위에 두고 **bidirectional InfoNCE**로 학습한다. 공식 카드에 따르면 약 60M Nemotron Q&A pair, 30M synthetic hard negative, 1M agentic trajectory가 단계별 학습에 쓰였다. state/action을 별도로 인코딩하므로 반복되는 action 후보 embedding을 캐시할 수 있다.

### 활용 가능성과 제약
공식 구성은 vLLM을 Qwen3-8B **pooling runner**로 띄우고 `clm-serve`가 ranking API를 제공한다. MCP/Agent에서 tool/action 선택이나 verifier/routing 보조 모델로 활용하기 좋다. projection head만 fine-tune할 수 있지만 현재 checkpoint는 Qwen3-8B pooled embedding에 고정돼 있고 자유 생성은 하지 않는다.

공식 카드의 “Jev 대비 최대 9× 낮은 latency”, DeepSWE **81.6%**, Terminal-Bench 2.1 **87.6%**, 4–6× 속도 우위 등은 **개발사 자체 평가**이며 독립 검증으로 간주하지 않았다.

## 3. apple/LensVLM-9B

- **개발사:** Apple
- **분야/규모:** Image-Text-to-Text / Document VLM, **9B**
- **계보:** Qwen3.5-9B 계열 기반
- **라이선스:** Apple Machine Learning Research Model License
- **공식 GitHub:** https://github.com/apple-aiml-research/ml-lensvlm
- **논문:** https://arxiv.org/abs/2605.07019

### 오늘 주목할 근거
조사 시점 Hugging Face Trending 두 번째 페이지에 있었고 **2일 전 업데이트, 월간 다운로드 455, 좋아요 187, Spaces 2**를 확인했다.

### 기술적 차이
긴 문서의 모든 페이지를 처음부터 고해상도 visual token으로 처리하는 대신, **압축된 텍스트 이미지를 먼저 훑은 뒤 질문에 필요한 페이지만 learned tool로 원해상도 확장**한다. 공식 demo는 5×/10×/15× compression을 제공한다. 긴 문서의 visual context 비용을 selective context expansion으로 줄이는 방식이다.

### 활용 가능성과 제약
Transformers의 `AutoModelForMultimodalLM`을 지원한다. Hugging Face 가이드는 **vLLM과 SGLang 모두 OpenAI-compatible API** 사용 예시를 제공한다. llama.cpp/Ollama/LM Studio용 파생 quantization 탐색 링크도 있다. 원본은 9B BF16이라 CPU-only PC에서 빠른 운용보다 GPU 또는 저비트 변환이 현실적이다. 가중치는 Apache/MIT가 아니라 Apple 연구 라이선스이므로 상업 사용·재배포 전 원문 검토가 필요하다.

## 4. Edge0/Audio8-ASR-Infinite

- **개발사:** Edge0 / Audio8
- **분야/규모:** Automatic Speech Recognition, native streaming, Hugging Face metadata **4B**, BF16, 약 8.17 GB weights
- **지원 언어:** 중국어·영어
- **라이선스:** Apache-2.0

### 오늘 주목할 근거
조사 시점 Trending 첫 페이지에 있었고 **약 20시간 전 업데이트, 월간 다운로드 347, 좋아요 약 305, Community 1, Space 1**을 확인했다.

### 기존 Audio8-ASR-0.1B와 별도 계열로 판단한 이유
`introduced-models.md`에는 Audio8-ASR-0.1B가 이미 있지만 Infinite는 단순 크기·양자화·포맷 변형이 아니다. 공식 카드 기준 **Voxtral Realtime 4B causal audio tower + 새 audio projector/frame-length embedding + Qwen2.5-3B-Instruct decoder/LM head**를 학습하고 DSM-style streaming을 사용한다. 80/120/160 ms selectable audio clock, 240–560 ms delay, rolling KV cache, exact RoPE rebasing, semantic VAD를 결합한다. native context 자체는 30초지만 rolling window로 메모리와 지연을 bounded 상태로 유지하며 장시간 transcription을 목표로 한다. architecture와 streaming 운용 목적 변화가 커 별도 계열 예외로 판단했다.

### 활용 가능성과 제약
Transformers에서는 `trust_remote_code=True`가 필요하다. 공식 장시간 배포 경로는 **adapted vLLM build + Docker Compose + WebSocket `/v1/realtime`**이다. 4B/약 8.17 GB BF16 weights라 저지연 CPU-only 운용보다는 GPU 환경이 현실적이다. 현재 preview는 중국어·영어 transcription 중심이다.

공식 AISHELL/LibriSpeech 비교 수치는 **개발사 자체 평가**다.

## 5. netease-youdao/Confucius4-T3PO

- **개발사:** NetEase Youdao AI Team
- **분야:** Text-to-Text Simultaneous Translation
- **규모:** Hugging Face metadata **15B**, 개발사 설명은 14B; base는 Qwen2.5-14B
- **주 지원:** 중국어↔영어
- **라이선스:** Apache-2.0
- **공식 GitHub:** https://github.com/netease-youdao/Confucius4-T3PO

### 오늘 주목할 근거
조사 시점 모델 페이지는 **월간 다운로드 859, 좋아요 49**를 표시했다. 최근 Translation 분야 Trending에서 주목받고 있으며, 같은 개발사의 streaming ASR R2T2와 cascade해 실시간 통역 파이프라인을 구성할 수 있다.

### 기존 Confucius4 계열과 별도인 이유
기존 인덱스의 Confucius4-TTS와 R2T2는 각각 음성 합성과 streaming ASR이다. T3PO는 **streaming text simultaneous translation** 모델이다. 입력 chunk마다 READ/WRITE를 결정하고 interleaved history protocol로 KV cache를 재사용하며, 확정된 translation prefix는 append-only로 유지한다. 개발사는 segment-aligned data construction → streaming cold start → **Pareto-aware reinforcement learning**의 3단계를 설명한다. 입력/출력 목적과 학습 방법, 실행 protocol이 달라 별도 계열로 판정했다.

### 활용 가능성과 제약
Transformers와 vLLM serving을 지원한다. native speech input은 없으므로 음성 통역은 streaming ASR을 앞단에 붙여야 한다. 주 학습·평가 범위는 중국어↔영어다. 다른 언어의 품질은 충분히 검증되지 않았다. 낮은 latency mode에서는 뒤 문맥을 기다리지 않고 번역을 확정하므로 품질이 낮아질 수 있다. 공개 benchmark는 **개발사 자체 평가**로 본다.
