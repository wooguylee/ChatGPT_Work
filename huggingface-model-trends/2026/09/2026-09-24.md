## 1. nvidia/Nemotron-3-Diarization

- Hugging Face: https://huggingface.co/nvidia/Nemotron-3-Diarization
- 개발사/작성자: **NVIDIA**
- 분야: **Audio / Speaker Diarization / Voice Activity & Speaker Activity Classification / Streaming Speech Pipeline**
- 규모: 모델 카드 기준 **100M**, Hugging Face 파일 정보 기준 **99.2M parameters**
- Architecture: **31-layer Transformer encoder + RoPE + AOSC + FIFO streaming cache**
- 라이선스: **Open Model Data License v1.1 (openmdw-1.1)**
- 공개일: **2026-09-23**
- Hugging Face snapshot: **120 likes, Community 3, Spaces 3, downloads last month 27**

### 오늘 주목할 근거

2026-09-23 공개된 직후 Hugging Face Trending에 진입했고, 조사 시점 모델 페이지에서 120 likes, Community 3, Spaces 3이 확인됐다. Trending 목록에는 약 **2시간 내 업데이트** 상태로 노출되었다. 다운로드는 공개 직후라 월간 27로 아직 작으며, 초기 공개 단계라는 점을 감안해야 한다.

NVIDIA가 같은 시점에 streaming ASR과 결합한 Hugging Face Space 및 통합 예제를 함께 공개해 단순 checkpoint 업로드보다 실제 speech pipeline 적용 준비도가 높다.

### 기술적으로 무엇이 달라졌나

Nemotron 3 Diarization은 음성을 글자로 바꾸는 ASR 모델이 아니라 **“누가 언제 말했는지”를 실시간 또는 offline으로 분리하는 speaker diarization 전용 모델**이다. 기존 인덱스의 `nvidia/Nemotron-3.5-ASR-Streaming`이나 `nvidia/Nemotron-3-Embed-1B`와는 입력은 일부 겹치더라도 **출력 목적과 모델 구조가 다르므로 별도 계열**로 판단한다.

핵심 구조는 다음과 같다.

- Sortformer 계열의 **arrival-order speaker stream**을 사용해 화자 permutation 문제를 첫 등장 순서로 정렬한다.
- streaming에서는 **Arrival-Order Speaker Cache(AOSC)**가 과거 chunk의 화자 정보를 유지하고, **FIFO queue**가 최근 frame context를 공급한다.
- 10 ms Mel-spectrogram feature를 8배 downsample해 Transformer encoder에서 **80 ms frame rate**로 처리한 뒤 Conv1D로 다시 10 ms 해상도의 speaker activity prediction을 만든다.
- 하나의 checkpoint가 streaming과 offline을 모두 지원하고 최대 **8 speakers**를 처리한다.
- 입력 buffer는 기술적으로 80 ms까지 가능하지만, 공식 카드의 권장 최저 구성은 **0.32 s**이며 offline-style 구성은 30.4 s다.
- chunked inference를 쓰면 공식 카드 기준 최대 audio duration에 고정 상한을 두지 않는다.

### 실제 활용 가능성과 제약

공식 경로는 **NVIDIA NeMo Speech**와 Hugging Face **Transformers** 두 가지다. Transformers에서는 `AutoProcessor`와 `AutoModelForAudioFrameClassification`으로 직접 불러올 수 있으며, 현재 카드 예시는 source install된 최신 Transformers를 사용한다.

실무적으로는 회의 녹취, 콜센터, podcast, multi-speaker ASR 앞단에서 speaker label/timestamp를 붙이는 용도가 가장 직접적이다. 특히 streaming ASR과 결합한 공식 demo가 있어 음성 Agent의 화자 구분 layer로 연결하기 좋다.

하드웨어 측면에서 parameter 수 자체는 작지만 공식 지원/검증 경로가 **Linux + NVIDIA GPU 중심**이며 Ampere/Ada/Hopper/Blackwell 계열 GPU 목록을 명시한다. 따라서 CPU-only 일반 PC에서 동일한 실시간 성능을 기대할 근거는 아직 없다. Hugging Face Inference Provider에 직접 배포되어 있지도 않다.

라이선스는 OpenMDW 1.1이며 모델 카드는 commercial/non-commercial use 가능하다고 명시한다. 실제 제품에서는 음성 개인정보·통화 녹음 규정은 별도로 검토해야 한다.

### Benchmark 주의

아래 수치는 **NVIDIA 개발사 자체 평가**다. 독립 검증 결과처럼 해석하지 않는다.

- DIHARD III full DER, 30.4 s 구성: **12.73** (`diar_streaming_sortformer_4spk-v2.1` baseline 19.09)
- NOTSOFAR1 MHM full DER, 30.4 s 구성: **6.77** (baseline 21.77)
- RTX PRO 5000에서 30.4 s 구성, batch 1: **RTFx 1340 eager / 4385 compiled**

평가 label·collar·hardware·latency 설정이 결과에 직접 영향을 주므로 다른 diarization 모델과 숫자만 단순 비교하면 안 된다.

## 2. paradigma-inc/limite-1b-violetto

- Hugging Face: https://huggingface.co/paradigma-inc/limite-1b-violetto
- 개발사/작성자: **Paradigma**
- 분야: **Text LLM / Mathematical Reasoning / Scientific Reasoning**
- 규모: **1B parameters**, dense autoregressive Transformer
- Context: **131,072 tokens**
- 라이선스: **Apache-2.0**
- Hugging Face snapshot: **57 likes, downloads last month 1,800**, Trending 노출, **Updated 1 day ago**
- 공식 GitHub snapshot: **84 stars / 4 forks / 13 commits**

### 오늘 주목할 근거

Hugging Face Trending에 진입했고 조사 기준 **1일 이내 업데이트** 모델로 표시됐다. 월간 다운로드 1.8k, 57 likes로 공개 초기 모델치고 실제 설치·실험 흔적이 빠르게 생기는 편이다. 공식 vLLM plugin repository도 84 stars와 13 commits가 확인된다.

Paradigma가 공개한 첫 모델이며, 기존 공개 checkpoint를 단순 fine-tune한 것이 아니라 **1B dense model을 from scratch로 pretrain한 신규 계열**이라는 점이 중복 제거 관점에서 중요하다.

### 기술적으로 무엇이 달라졌나

공식 자료가 확인해 주는 범위에서 Violetto는 다음 특성을 가진다.

- **1B dense autoregressive Transformer**를 처음부터 학습했다.
- pretraining은 **300B 미만의 고도로 curated된 token mixture**를 사용했다.
- 이후 synthetic data generation, curated SFT, RL post-training을 결합해 **competition-level mathematics**에 특화했다.
- 최대 **131k context**를 지원한다.
- assistant persona와 범용 instruction following을 강하게 학습하기보다는 **한 번에 하나의 수학 문제를 깊게 푸는 single-turn reasoner**로 설계했다.
- Hugging Face `config.json`의 model type은 `limite`이며, 현재 공개 serving은 일반 Transformers 기본 경로가 아니라 **전용 vLLM plugin**이 architecture를 등록하는 방식이다.

즉 단순히 작은 Qwen/Llama를 수학 데이터로 fine-tune한 모델이 아니라, pretraining 단계부터 별도 architecture family와 데이터/학습 recipe를 가진 신규 1B reasoning model이다.

### 실제 활용 가능성과 제약

공식 지원 환경은 **Linux x86-64 + NVIDIA GPU + Python 3.12 + vLLM 0.26.0 + PyTorch 2.11.0(CUDA 13.0)** 조합이다. 실행 시 `VLLM_PLUGINS=limite`로 공식 plugin을 활성화해 `vllm serve`를 사용한다.

1B라 parameter 규모는 작지만, 현재 공식 문서 기준으로는 일반적인 `transformers.from_pretrained()` 직접 호환이 아직 제공되지 않으며 **Transformers native compatibility는 “coming soon”**으로 적혀 있다. llama.cpp/Ollama/LM Studio 공식 지원도 확인되지 않는다. 따라서 오늘 시점의 실무 배포는 전용 vLLM 환경을 따르는 편이 안전하다.

범용 챗봇으로 쓰는 것도 적합하지 않다. 공식 예시에서도 일반 상식 질문을 수학 문제로 잘못 재해석하는 failure mode를 공개하고 있다. 수학 solver, 연구용 reasoning worker, batch problem-solving service처럼 **좁은 역할을 맡기는 구성**이 더 적절하다.

Apache-2.0으로 weights와 serving code가 공개되어 상업적 이용 장벽은 비교적 낮다.

### Benchmark 주의

성능 수치는 **Paradigma 개발사 자체 평가**다. 일부 비교 대상 수치는 모델 카드 또는 MathArena에서 가져왔고 평가 설정이 다를 수 있다고 개발사도 명시한다.

- BeyondAIME 평균: **74.25%**
- 공식 release blog figure의 AIME 2026: **94.01%**

모델 규모 대비 인상적인 수치지만 독립 재현 전에는 absolute ranking으로 받아들이지 않는 것이 적절하다.

- 공식 release blog: https://paradigma.inc/blog/limite-1b-violetto/

## 3. vamboai/morena-1.5b-base

- Hugging Face: https://huggingface.co/vamboai/morena-1.5b-base
- 개발사/작성자: **Vambo AI / Isheanesu Misi**
- 분야: **Text LLM / Multilingual Foundation Model / African Languages**
- 정확한 규모: **1.485B parameters**
- Architecture: **decoder-only, 28 layers × hidden 2048, GQA 16/4, SwiGLU 6144, RoPE theta 500,000**
- Context: **4,096 tokens**
- Tokenizer: **65,536-entry byte-fallback BPE**
- 라이선스: **Apache-2.0**
- 공개일: **2026-09-18**
- Hugging Face snapshot: **2 likes, downloads last month 32**, MORENA collection **39 likes / updated 5 days ago**

### 오늘 주목할 근거

MORENA는 Hugging Face Trending 최상위 모델은 아니지만 **2026-09-18 공개된 매우 최근의 신규 foundation family**이고, 기술적 가치가 단순 인기 순위보다 크다고 판단했다. 12개 Latin-script African languages를 중심 목표로 **from scratch** 학습한 소형 foundation model이라는 점이 희소하다.

현재 likes 2, 월간 다운로드 32로 대중적 관심은 아직 작으므로 “급상승 인기 모델”로 과장하지 않는다. 이번 선정은 **최근 공개 + 저자원 언어 foundation model의 기술적/개발 생태계 가치**에 더 큰 비중을 둔 것이다.

### 기술적으로 무엇이 달라졌나

MORENA 1.5B base는 기존 공개 LLM checkpoint를 fine-tune한 파생물이 아니라 처음부터 학습한 모델이다.

- pretraining **251.7B tokens** + mid-training **63B tokens**, 총 **315B tokens seen**
- 12개 African languages: Shona, Swahili, Hausa, Yoruba, Igbo, isiZulu, isiXhosa, Kinyarwanda, Setswana, Afrikaans, isiNdebele, Nigerian Pidgin
- 여기에 English, French, code를 함께 학습
- target language mix에 맞춘 **65,536-entry byte-fallback BPE tokenizer** 사용
- non-embedding weight에는 **Muon**, 나머지에는 AdamW를 사용한 optimizer 구성
- family는 1.5B base/instruct, 0.5B mini/mini-instruct, 0.2B nano로 구성되며 mini/nano는 같은 MORENA 계열의 pruning/distillation 파생으로 취급한다.

이 모델의 핵심 변화는 거대 범용 LLM의 작은 fine-tune이 아니라 **아프리카 언어 tokenization과 pretraining mixture 자체를 목표 언어에 맞춰 새로 설계한 foundation model**이라는 점이다.

### 실제 활용 가능성과 제약

`morena-1.5b-base`는 **chat model이 아니다.** 공식 카드는 fine-tuning, continued pretraining, domain adaptation의 출발점으로 권장한다. 대화·번역·tool calling이 필요하면 같은 family의 1.5B instruct checkpoint가 역할상 더 적합하다.

1.485B의 비교적 작은 모델이지만, 오늘 시점 Hugging Face Inference Provider 배포는 없으며 모델 repository에는 custom `modeling_morena.py`가 포함되어 있다. 공식 카드에서 vLLM/SGLang/llama.cpp/Ollama/LM Studio 호환을 보장하지 않으므로 해당 runtime 지원을 추측하지 않는다.

Apache-2.0으로 **상업적 fine-tuning과 derivative 재배포가 허용**된다고 공식 카드가 명시한다. 다만 training corpus 자체는 weights와 함께 공개되지 않는다.

### Benchmark 주의

아래는 모두 **Vambo AI 개발사 자체 평가**다.

- 12개 African language 평균 bits-per-byte: **1.408**
- FLORES+ English → 5 African languages 3-shot chrF++: **43.2**
- FLORES+ 5 African languages → English 3-shot chrF++: **47.8**
- MMLU: **0.284**

공식 카드 스스로 범용 factual knowledge를 일부 희생했다고 설명하며, base checkpoint에는 safety evaluation이 적용되지 않았다고 적고 있다. 따라서 저자원 언어 적응 기반 모델로 보는 것이 맞고, 일반 목적 assistant의 대체재로 해석하면 안 된다.

### 주요 1차 출처

- Hugging Face 모델 카드: https://huggingface.co/vamboai/morena-1.5b-base
