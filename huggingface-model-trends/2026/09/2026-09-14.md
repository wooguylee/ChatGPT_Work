## 1. internlm/Atria-Dawn-Preview

### 기본 정보

- Hugging Face: https://huggingface.co/internlm/Atria-Dawn-Preview
- 개발: **Shanghai Artificial Intelligence Laboratory / InternLM**
- 분야: Agent, Research Automation, Coding, Tool Use, Office/Delivery, Authorized Cybersecurity
- 규모: Hugging Face 표시 **753B params**. 공식 카드 설명상 **744B MoE GLM-5.2 foundation model 기반**
- 입력: **text-only**
- context length: **256K**
- 라이선스: **MIT**

### 오늘 주목할 근거

Hugging Face Trending 목록에서 공개 직후 빠르게 올라왔고, 조사 시점 모델 페이지는 약 **53 likes**, 최근 업데이트는 약 **4시간 이내**였다. 공식 GitHub `atria-asi/Atria-Dawn-Preview`도 공개 직후 약 **76 stars**를 기록하고 있다. 다운로드 수치는 아직 안정적인 snapshot이 표시되지 않아 적지 않는다.

### 기존 모델과의 기술적 차이 / 별도 모델 판단

Atria Dawn Preview는 GLM-5.2 foundation을 사용하므로 완전히 새로운 base architecture라고 표현하면 안 된다. 그러나 공식 자료는 이 checkpoint를 단순 instruction fine-tune이 아니라 **새로운 세대의 agentic model**로 정의하고, 목표를 일반 대화가 아니라 환경 피드백을 계속 받아 `문제 분석 → 계획 → tool use → code implementation → experiment execution → result analysis → failure recovery`까지 완료하는 end-to-end agent workflow에 둔다.

`introduced-models.md`에는 GLM-5.2와 GLM-5.3 계열이 이미 존재하지만, 이번 checkpoint는 일반 LLM의 크기/양자화 변형이 아니라 **agent/tool 구조와 근본 목적을 연구·엔지니어링 자동화로 크게 바꾼 별도 post-trained agentic checkpoint**라는 공식 1차 출처 설명을 근거로 예외적으로 신규 계열로 판단한다. 다만 학습 recipe의 세부 내용은 현재 공개 자료에서 충분히 설명되지 않았으므로, base architecture 자체가 새롭다고 주장하지 않는다.

### 평가

공식 모델 카드가 공개한 수치는 **개발사 자체 평가**다. 예를 들어 AutomationBench 53.8, BFCL v4 77.0, DeepSearchQA 96.0, Workspace-Bench 65.0, SWE-bench Pro 59.6 등을 제시한다. 이는 독립 검증 결과로 간주하지 않는다.

### 실제 활용 가능성과 제약

- 로컬 serving: 공식 가이드 기준 **SGLang v0.5.13.post1+**, **vLLM v0.23.0+** 지원
- Hosted API: `https://api.atria-asi.ai/v1`에서 OpenAI Responses API 스타일 provider 설정을 제공
- Codex: 공식 README에 Codex CLI custom provider 설정 예제가 있으며, `wire_api = "responses"` 사용
- Claude Code: 공식 README에 text-only 제약을 다루는 hook 예제를 제공
- 일반 PC 실행: 753B급 weight이므로 현실적으로 불가능에 가깝고, 대규모 multi-GPU/server 또는 hosted API가 필요
- 중요한 제약: **text-only** 모델이므로 Codex에서 이미지/PDF 입력을 자동 전달하면 오류가 날 수 있어 `input_modalities: ["text"]` 등 명시가 필요
- 라이선스: MIT로 공개되지만 실제 서비스 사용 시 hosted API 약관은 별도 확인 필요

## 2. oruk/orukeet

### 기본 정보

- Hugging Face: https://huggingface.co/oruk/orukeet
- 개발: **Oruk AI** 연구진 및 협력 연구자
- 분야: Automatic Speech Recognition, Multilingual ASR, On-device/Local Speech
- 규모: **627,008,134 parameters (약 0.6B)**
- 기반: `nvidia/parakeet-tdt-0.6b-v3`
- 지원 언어: **25 languages**
- 라이선스: code MIT, weights/fitted kernels **CC BY-SA 4.0**

### 오늘 주목할 근거

Hugging Face 전체 Trending 및 ASR Trending에서 빠르게 상승하고 있다. 조사 시점 전체 Trending 페이지에서는 약 **4.37K downloads**, **38 likes**, 최근 업데이트 약 **15시간 이내**로 표시됐다. 모델 카드와 evidence 디렉터리도 최근 계속 갱신되고 있으며 NeMo, ONNX INT8, native Q8/F16, `transcribe.cpp`용 GGUF를 함께 제공한다.

### 기존 모델과의 기술적 차이 / 별도 모델 판단

Orukeet은 Parakeet TDT 0.6B v3의 단순 fine-tune만은 아니다. 공식 카드에 따르면 24-layer FastConformer encoder의 temporal depthwise filters 24,576개 중 **12,288개를 fitted Gabor function으로 근사한 뒤 고정(frozen)**한다. 선택된 110,592 filter tap은 학습 중 고정되고, 나머지 약 626.9M scalar parameters가 학습된다.

즉 parameter 수와 전체 Parakeet TDT 골격은 유지하지만 encoder의 시간축 convolution 표현을 절반가량 **Gabor-structured frozen filters**로 바꾸고, transducer loss + encoder matching + token/duration distillation을 사용한 뒤 multilingual·multi-accent adaptation을 수행한다. 따라서 단순 adapter/양자화/포맷 변환보다 구조·학습 방법 변화가 충분히 크다고 판단해 별도 계열로 선정한다.

### 평가

모델 카드와 기술 보고서가 제시한 수치는 **개발사 자체 평가**다. 동일 조건의 Parakeet TDT 0.6B v3와 비교해 LibriSpeech test-clean WER 1.46% vs 1.53%, test-other 2.86% vs 3.14%, 25개 FLEURS 언어 pooled WER 9.85% vs 11.01%를 보고한다. 74개 split 중 61개에서 Parakeet보다 낮은 error를 보였다고 설명한다. 독립 검증으로 표현하지 않는다.

### 실제 활용 가능성과 제약

- NeMo: `nemo_toolkit[asr]==3.0.0` 기반 공식 예제 제공
- ONNX: **INT8** archive 제공, `sherpa-onnx` 기존 Parakeet loader 사용 가능
- Local/native: Apple Silicon Metal, NVIDIA CUDA, CPU를 자동 선택하는 native runtime 제공
- GGUF: Q8/F16 및 `transcribe.cpp`용 Q8 export 제공
- 파일 크기: 공식 카드 기준 NeMo 약 2.51GB, native Q8 약 714MB, transcribe.cpp Q8 약 740MB, native F16 약 1.30GB, ONNX INT8 archive 약 487MB
- 일반 PC: 0.6B 규모이므로 Atria와 달리 CPU/Apple Silicon/일반 소비자 GPU에서도 실용적인 로컬 ASR 후보
- llama.cpp/Ollama/LM Studio: 일반 text LLM용 runtime이 아니라 ASR 전용 `transcribe.cpp`/NeMo/sherpa-onnx 경로가 중심
- 제한: speaker diarization/emotion/style 출력은 제공하지 않으며, 모델 카드 기준 단일 ASR transcription 중심
- 라이선스 주의: weights가 CC BY-SA 4.0이므로 상용 배포 시 attribution과 share-alike 조건을 검토해야 함
