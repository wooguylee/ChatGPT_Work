## 2. ZONOS3-Mini: 로컬 다국어 음성 합성

### 신규 계열 판정

[공식 모델 카드](https://huggingface.co/Zyphra/ZONOS3-Mini/blob/main/README.md)는 **11층·hidden 1,024**, 64 experts 중 top-2를 선택하는 latent MoE, **9 Gated DeltaNet + 2 global-attention 층**을 명시한다. 여기에 attention residuals, 32,768-position 설정, 8,192-entry SuperBPE 텍스트 tokenizer를 결합한다.

음성은 초당 15개 frame의 **10개 codebook**으로 생성한다. 첫 codebook은 Wav2Vec2-BERT teacher의 의미 표현을 증류하고, 나머지 9개는 음향 정보를 담당한다. 다음 frame의 codebook들을 autoregressive delay pattern으로 예측하며, causal multi-resolution iSTFT head가 **44.1kHz 음성**으로 순차 복원한다. 참조 음성의 codec-token prefix 또는 192차원 speaker embedding을 조건으로 사용한다.

[11/09 공식 발표의 학습·구조 설명](https://www.zyphra.com/our-work/zonos3-mini#training-and-architecture-details)은 기존 ZONOS2의 8B·86Hz DAC 경로와 대비해 자체 ZAC-1 codec 학습, 새 혼합 MoE 백본, MECT-B2 화자 encoder와 DPO→GRPO 후학습을 설명한다. 이 구조·학습 근거에 따라 **아카이브에 없던 ZONOS3-Mini 음성 생성 계열의 첫 소개**로 판정한다. 단순히 작은 배포 파일이 생겼다는 이유로 선정하지 않았다.

Wav2Vec2-BERT 등 외부 구성요소 재사용을 인정하며 전 구성요소를 처음부터 학습했다고 주장하지 않는다. 정확한 가중치 초기화 계보·전체 학습 데이터 구성은 미확인이다. 같은 Mini 백본의 GGUF·WebGPU·MLX·decoder 가지치기 배포는 모두 한 계열로 묶는다. [공개 checkpoint 문서](https://github.com/Zyphra/ZONOS3-Mini/blob/main/docs/release_checkpoints.md)는 `model_type="zonos2"`가 checkpoint-format 이름이라고 설명하므로 해당 문자열만으로 이전 세대의 재포장으로 단정하지 않는다.

**태그:** text-to-speech, multilingual, voice-cloning, on-device, latent-MoE, Gated-DeltaNet, streaming, WebGPU, ko.

### 활용 예와 평가 방법

[공식 카드의 SGLang-Omni 경로](https://huggingface.co/Zyphra/ZONOS3-Mini#with-sglang)는 OpenAI 호환 `/v1/audio/speech` 요청을 제공한다. 다음은 검토한 의존성과 가중치를 준비하고 로컬 서버를 띄운 뒤 보내는 **미실행 요청 예시**다. 외부 API를 호출하거나 다른 사람의 음성을 업로드하지 않는다.

~~~bash
curl -X POST http://localhost:8000/v1/audio/speech \
  -H "Content-Type: application/json" \
  -d '{"input": "안녕하세요. 오늘 회의는 오후 세 시에 시작합니다."}' \
  --output korean-test.wav
~~~

이는 기본 음성으로 한국어 합성이 되는지 확인하는 작은 출발점이다. 실제 평가에서는 한국어 기본 음성을 명시적으로 선택하고 숫자·날짜·영문 혼합·고유명사 문장을 따로 준비한다. 원문 누락·반복·발음 오류, 첫 음성 지연, 긴 문장의 품질과 메모리를 함께 측정한다. 음성 복제는 본인 또는 사용에 동의한 화자의 녹음으로만 평가하고 합성 음성임을 알린다.

공식 지원 목록은 한국어를 포함한 **43개 언어**다. language tag·정규화 지원은 한국어 발음 품질을 보증하지 않는다. 10분 생성 안내와 32,768-position 설정도 모든 장문에서 안정적인 품질을 뜻하지 않는다.

카드의 첫 음성 **80ms**·최대 처리량 **457 audio-seconds/second**는 H100 80GB의 제작자 평가다. 전자는 8개 동시 요청, 후자는 모델별 최적 동시성 조건이므로 단일 요청 속도와 합쳐 읽지 않는다. 한국어만의 독립 benchmark나 휴대전화 측정치로 사용하지 않는다.

[공식 런타임 저장소](https://github.com/Zyphra/ZONOS3-Mini)는 NVIDIA CUDA·Apple Silicon MLX·C++/ggml·브라우저 WebGPU 경로를 구분한다. 설치·초기 다운로드·커널 컴파일·브라우저 캐시가 필요할 수 있다. 100M active는 token당 활성 규모이며 전체 가중치 저장량이나 RAM 요구량이 아니다. 장치별 최소 메모리·모바일 지속 속도는 이번에 측정하지 않았다.

## 3. 오늘 확인한 제외·보류 후보

아래 모델은 신규 소개 수와 색인 추가 대상에 넣지 않는다.

- **[MiniMax-H3-Image](https://huggingface.co/MiniMaxAI/MiniMax-H3-Image): 기존 H3 직접 분기 제외.** 오늘 확인한 공식 카드에서 H3-Base의 audio branch 제거, 동일 H3 text encoder, 동일 50층·33.1B DiT와 6-step 증류를 확인했다. 고해상도 이미지 생성·편집의 실무 가치는 있지만 새 독립 백본이나 주요 차세대 학습을 입증하는 자료는 확보하지 못했다. MiniMax-H3-Image Community License이며 33.1B는 DiT만의 크기다. 기존 PrunaAI/P-H3-Image와 이름을 혼동하지 않는다. 카드의 수정 시각을 최초 출시 시각으로 쓰지 않는다.
- **[Arete-27B](https://huggingface.co/NousResearch/Arete-27B): 직접 SFT 제외.** Nous Research가 Qwen3.8-27B에서 출발하고 SFT만 사용하며 architecture modification이 없다고 명시한다. 공식 약 27B·Apache-2.0 표기. 제작자 가치 정렬 평가 결과를 새 계열의 근거로 바꾸지 않는다.
- **[Viggle-Remake](https://huggingface.co/Viggle/Viggle-Remake): H3 LoRA 제외 유지.** swap/edit 각각 MiniMax-H3 transformer의 rank-256 LoRA다. MCP 제작 흐름·저정밀 포맷·장면 편집 옵션을 별도 모델 계열로 세지 않는다. 가중치는 MiniMax H3 Community License, 실행 코드 Apache-2.0이며 출력 음향은 원본 soundtrack을 복사한다.
- **[Mithi v1 Flash](https://huggingface.co/Oomni/mithi-v1-flash): 계보·학습 검증 보류.** Oomni의 공식 약 99.1M·11개 언어·24kHz·고정 2음성 TTS다. [config](https://huggingface.co/Oomni/mithi-v1-flash/blob/main/config.json)는 trimmed IndicBERT, GRPO step 2,400의 prosody writer, 62,000-step fine-tuned Kokoro text encoder/iSTFTNet decoder를 명시한다. 새 writer의 초기화·전체 학습 recipe·기존 음성 계열과의 차이를 충분히 확인하지 못해 독립 신규 판정을 보류한다. [Apache-2.0 LICENSE 전문](https://huggingface.co/Oomni/mithi-v1-flash/blob/main/LICENSE)은 확인했으며 카드도 공개 자동 평가·MOS가 없다고 밝힌다.
- **[Idol](https://huggingface.co/speridlabs/idol)·[Underdog-Woof](https://huggingface.co/ConwayResearch/Underdog-Woof): 보류 유지.** [11/08](2026-11-08.md)·[11/10](2026-11-10.md)의 초기화·학습 계보 미확인 사항을 해소할 새 1차 근거를 확보하지 못했다. Idol은 TripoSplat 자체가 이미 색인에 있다는 뜻으로 제외하지 않는다. Woof는 Mimi decoder 재사용만으로 Pocket-TTS 직접 파생이라고 단정하지 않는다. Woof 비상업 라이선스 전문은 이전에 확인됐으므로 미확인 상태로 되돌리지 않는다.

기존 Ripple·Kimi-K3.1·ERNIE·LFM3·RelayVSR·P-JiT·Mirage·MNN-Pocket·LongCat-2.5와 이들의 단순 크기·양자화·포맷 변형도 재등록하지 않는다.
