## 1. 긴 문맥에서 일부 블록을 골라 보는 방식

[개발사 기술 글](https://maxwell-llm.ai/research/maxwell-v1-flash)과 모델 카드는 45층 MoE, 네 개의 잔차 스트림, 학습된 블록 선택기를 설명한다. 희소 어텐션 구간에서는 KV 그룹마다 앞쪽과 가까운 문맥의 블록을 고정해서 보고, 멀리 있는 블록은 중요도를 계산해 선택한다. 한 그룹이 한 번에 직접 참조하는 범위를 제한하지만 전체 이력의 KV 캐시가 없어지는 것은 아니다.

- **신규성:** 제작자는 약 26조 토큰의 다국어 사전학습, 128K 중간 학습에서의 희소 어텐션 전환, 이후 256K까지의 문맥 훈련을 설명한다. [배포 구현](https://huggingface.co/maxwell-model/Maxwell-V1-Flash/blob/main/modeling_maxwell_moe.py)도 확인했다. 평가표의 Qwen은 비교군이다. 정확한 가중치 초기화와 전체 학습 데이터는 독립 검증하지 않았으나, 별도 구조와 단계별 사전학습 근거로 최초 계열 소개에 포함했다. FP8 등은 별개로 세지 않았다.
- **규모와 평가:** HF 카드의 저장 집계는 약 37B로, 제작자의 임베딩 제외 수치와 기준이 다르다. 제작자가 보고한 256K 어텐션 커널 속도 비교는 전체 추론이나 작업 완료 시간이 아니다. 한국어 품질, 최소 VRAM, 사용자 장치 속도는 확인하지 않았다.
- **활용 예:** 가상의 계약서 변경 이력에 같은 이름과 다른 날짜를 여러 위치에 넣은 뒤, 8K·32K·64K 입력에서 최종 적용 날짜와 근거 문단을 요청한다. 정답률·근거 일치율·첫 응답 지연·메모리를 각각 기록한다. 공식 모델 경로의 사용자 지정 코드는 먼저 검토하고 리비전을 고정한다.
- **태그:** MoE, text generation, long context, sparse attention, multilingual.
- **시점:** [HF 초기 커밋](https://huggingface.co/maxwell-model/Maxwell-V1-Flash/commit/5a278bd2a16768614e9124cd0cd77dc055ced2a4)과 제작사 글을 확인했다. 11월 23일 KST는 관찰일이며, 가중치 최초 공개 전환 시각은 미확인이다.
