# 2026-11-19 Hugging Face 모델 트렌드

- **관찰일:** 2026-11-19, Asia/Seoul(KST).
- **신규 소개: 1개 계열. Top Pick: KORMo의 한국어·영어 시각 계열.** 트렌딩에 등장한 KORMo-Web-11B를 계기로, 아직 기록하지 않은 기반 KORMo-VL과 웹 특화판을 **한 계열**로 소개한다. 둘을 별도 신모델로 세지 않는다.

## 선정 요약

|---|---|---|---|
| [KORMo-VL](https://huggingface.co/KORMo-VL/KORMo-VL)·[KORMo-Web-11B](https://huggingface.co/KORMo-VL/KORMo-Web-11B) / KAIST MLP Lab | 웹판 HF 표시 약 11B, BF16. 스크린샷·텍스트 → 설명 또는 UI 행동 제안 | 웹판 모델 카드 Apache-2.0 표기. 의존 코드·데이터의 사용 조건은 별도 확인 | 독자 사전학습한 한·영 KORMo-10B에 SigLIP 시각 인코더를 붙인 KORMo-VL 계보. 웹 특화판에는 UI 이해와 다단계 행동 학습이 추가됨 |

## 구조와 사용 범위

[원본 언어 모델 자료](https://huggingface.co/collections/KORMo-Team/kormo-10b)와 [KORMo-VL 카드](https://huggingface.co/KORMo-VL/KORMo-VL)에 따르면 독자적으로 사전학습한 이중언어 텍스트 모델을 시각 입력으로 확장했다. 웹판은 이 시각 백본을 재사용하며, [웹판 카드](https://huggingface.co/KORMo-VL/KORMo-Web-11B)는 한·영 UI 요소 이해 샘플 1,000만 건 이상과 웹 상호작용 궤적 10만 건 이상을 설명한다. 초기부터 완전히 새로 학습한 웹 모델이라는 뜻은 아니다. 같은 계열의 크기 변형이나 포맷 변환은 별도 집계하지 않는다.

- **관찰과 출시 구분:** 기반 KORMo-10B의 논문은 2025년 10월 공개됐다. 웹판은 11월 19일 KST [트렌딩 첫 페이지](https://huggingface.co/models?sort=trending)에서 관찰했다. 웹판의 최초 공개 전환 시각과 순위 상승 폭은 확인하지 못했다.
- **제작자 자체 평가:** Online-Mind2Web의 제작자 설정에서 웹판 11B는 한국어 312개 과제에 대해 30.1%, 영어 300개 과제에 대해 29.0% 성공을 보고했다. 사용한 평가 모델과 과제 구성이 정해진 결과로, 실제 서비스의 성공률을 뜻하지 않는다. 같은 카드에서 4B·9B 웹 특화판이 웹 과제 성공률은 더 높았다고 명시한다.
- **실행 제약:** 공식 문서에는 Transformers 5와 vLLM 경로가 있다. 약 11B BF16은 단순 계산으로 가중치에만 약 22GB가 필요하고, 이미지 처리·문맥 캐시 및 런타임 메모리는 별도다. 따라서 VRAM 24GB에서의 실행을 보장할 수 없다. 사용 환경에서 실행이나 속도는 검증하지 않았다.
- **활용 예:** 로그인·외부 시스템 조작 없이, 직접 만든 한국어 데모 폼의 정적 스크린샷에서 «저장 버튼 위치와 입력 오류가 표시된 항목을 설명해 줘»처럼 시각 이해를 평가한다. 화면 이해 품질과 실제 행동 수행 성공률은 별도로 본다.
- **태그:** 한국어, 영어, VLM, 스크린샷, LLaVA-OneVision, SigLIP.

## 신규 수에서 제외한 후보

- [FastFrames-L](https://huggingface.co/apple/FastFrames-L): 두 단계 생성 및 캐시 개선은 주목할 만하나 공식 카드에서 Wan2.1-14B 직접 증류 계보를 확인했다. 이 보고서의 신규 계열에는 넣지 않았다.
- [Rumble-2-Flash](https://huggingface.co/blog/rumble-2-flash): 11월 18일 공개 발표가 있지만 제작자가 Rumble-2의 직접 증류라고 명시했다. 공개 시점과 별도 계열 여부는 다르다.
- [Hy4-flash](https://huggingface.co/tencent/Hy4-flash): 이전에 등록한 Hy4 계열과 독립적인 구조·학습 차이를 확인하지 못해 별도 집계하지 않았다.

## 관찰 범위와 직전 7일 비교

[트렌딩 첫 페이지](https://huggingface.co/models?sort=trending)와 [둘째 페이지](https://huggingface.co/models?p=1&sort=trending), [최근 수정 목록](https://huggingface.co/models?sort=lastModified)을 함께 확인했다. 직전 7일(11/12~18) 저장소 보고서에서는 신규 계열 6개를 기록했다. 바로 전날 tiny-voca는 CPU 영어 음성 합성, 오늘 KORMo 항목은 한국어 포함 시각 인터페이스 이해가 주제다. 두 모델의 직접 성능 비교를 뜻하지 않는다.
