## 2. PAN 2: 행동의 예상 결과를 영상으로 만드는 별도 생성 계열

### 신규성 및 학습 계보

[공식 모델 카드](https://huggingface.co/IFM/PAN2/blob/a7936f7bea20ec3b9de809583712b40693071819/README.md)는 29B MMDiT를 구조화된 설명이 붙은 **수억 개 영상으로 처음부터 학습**했다고 명시한다. 이 설명은 생성 백본에 한정된다. Qwen3.5-9B와 Wan2.2는 동결된 외부 text encoder·VAE로 사용하며, 모든 구성요소를 처음부터 만든 모델이라고 쓰지 않는다.

개념 추론 LLM은 관찰·행동을 읽어 등장 주체, 시간에 따른 사건·행동, 카메라 움직임을 구조화된 설명으로 바꾼다. 지각 생성 백본은 이 설명과 선택적 첫 프레임을 조건으로 다음 관찰 영상을 만든다. 개념 추론은 별도 선택 가능한 LLM이며, PAN 2 가중치 하나가 모든 텍스트 추론까지 수행한다는 뜻은 아니다.

[공식 구현 설명](https://github.com/ifm-ai/PAN2#model)과 [배포 config](https://huggingface.co/IFM/PAN2/blob/a7936f7bea20ec3b9de809583712b40693071819/transformer/config.json)를 대조했다.

- **44개 video/state dual-stream joint-attention 블록**, hidden 4,096, 32 attention heads 및 3D RoPE.
- Wan2.2의 48-channel latent를 사용하고 patch는 1×2×2다.
- 입력은 noisy 48 + condition 48 + mask 1의 **97 channels**, 출력은 48 channels다.
- flow matching으로 480p 사전학습 → 720p 추가 사전학습 → 720p SFT를 수행한다.

공개 저장소는 reward learning·model soup가 최종 가중치에 사용됐지만 해당 학습 코드는 포함하지 않는다고 밝힌다. 전체 재현 recipe가 완전히 공개됐다고 안내하지 않는다.

기존 색인의 IFM/K2-Horizon 언어 계열이나 Wan 영상 checkpoint의 경미한 fine-tune으로 판정하지 않는다. **PAN 계열의 이번 아카이브 첫 소개**이며 PAN 1 대비 모든 차이를 검증한 차세대 비교라는 뜻은 아니다. Diffusers/native 포맷, 향후 같은 백본의 양자화·크기 변형은 별도 신규 수로 세지 않는다.

**태그:** world-model, world-simulation, image-text-to-video, text-to-video, diffusion-transformer, flow-matching, simulative-reasoning, research, en.

### 권리와 도입 조건

[HF LICENSE 전문](https://huggingface.co/IFM/PAN2/blob/a7936f7bea20ec3b9de809583712b40693071819/LICENSE)은 MBZUAI의 Apache-2.0이다. [NOTICE](https://huggingface.co/IFM/PAN2/blob/a7936f7bea20ec3b9de809583712b40693071819/NOTICE)는 Wan2.2·Qwen3.5-9B·Diffusers의 원천 고지를 구분한다. 카드 안에 PAN2-TEST를 가리키는 링크가 남아 있으므로, 이번에는 실제 **IFM/PAN2 경로의 LICENSE**를 직접 확인했다. 입력 영상·인물·학습 데이터 전체 권리가 자동으로 보증되는 것은 아니다.

[추론 문서](https://github.com/ifm-ai/PAN2/blob/main/docs/inference.md)에 따르면 기본 launcher는 GPU마다 **전체 29B 모델을 하나씩** 올려 프롬프트를 나눈다. GPU 여러 장이 자동으로 단일 모델 메모리를 분할해 준다는 뜻이 아니다. 별도 block/model offload 옵션은 있지만 정확한 최소 VRAM·사용자 장비 속도는 이번에 측정하지 않았다.

공식 기본값은 50 steps, CFG 2.5, **704×1248·24fps**, 기본 약 10초, 최대 20초다. 24fps는 출력 재생률이지 실시간 생성 속도가 아니다. 공개 가중치는 Diffusers 배치이므로 원본 CLI 사용 전 native 형식으로 변환해야 한다. 설치·다운로드·실행은 하지 않았다.

### 실무 활용 예: 성공·실패 계획을 나눠 검증

직접 만든 장면 사진으로 “컵을 빈 접시 위에 올린다”와 “막힌 서랍을 당긴다” 같은 안전한 행동을 비교한다. 여러 seed에서 행동 순서, 물체 지속성, 접촉·가림, 불가능한 상태 전이를 사람이 채점하고 실제 촬영 결과와 대조한다. 예측 영상이 그럴듯하다는 이유만으로 실제 행동을 실행하지 않는다.

검토한 환경과 native 변환 가중치, 구조화된 prompt JSON을 준비한 뒤 사용할 **미실행 예시**다.

~~~bash
NUM_GPUS=1 SEED=123 bash inference/inference.sh \
  /models/PAN2-native/transformer \
  outputs/pan2_20261112 \
  own_structured_prompts.json
~~~

[공식 문서](https://github.com/ifm-ai/PAN2/blob/main/docs/inference.md#5-prompt-rewriting)에 맞춰 free-text를 먼저 로컬 LLM으로 재작성하거나 사람이 구조화한다. generate.py는 입력을 그대로 encoder에 전달하므로 자동 재작성을 기대하지 않는다. 새 출력 폴더를 사용하고 원본 입력을 보존한다. 별도 요청/출력 guardrail과 사람 검수를 적용한다.

공식 카드가 밝힌 한계는 중요하다. 긴 계획 약 3분의 2에서 적어도 한 단계가 실패하며, 성공하도록 설계한 open-loop 계획 중심 평가라 **실패해야 할 계획을 정확히 실패로 시뮬레이션하는지는 아직 측정되지 않았다.** 프롬프트 민감성, clip 간 외형 변화, 물리적 중간 단계 생략도 있다. benchmark와 안전 수치는 제작자 평가이며 이번에 재현하지 않았다. 한국어 prompt 품질도 미확인이다.
