## 1. Nemotron-Labs-Image: 문장 대신 시각 토큰 출력

공식 모델 카드에 따르면 Nemotron 3 Nano에서 초기화한 모델에 시각 어휘를 추가하고 점진적 중간 학습과 GRPO를 적용했다. 별도 시각 토크나이저의 디코더가 생성된 토큰을 픽셀로 복원한다. 기존 Nemotron의 크기 또는 정밀도만 바뀐 것이 아니라, 학습 목표와 출력 양식이 달라진 주요 확장이다. 독립 언어 백본을 처음부터 학습했다는 뜻은 아니다.

- **실제 공개 범위:** 모델 카드가 명시한 초기 배포는 이미지 생성기·시각 토크나이저·추론 코드다. 같은 카드에서 소개하는 편집 가능 문서·SVG 제작용 전체 하네스와 VisionCode는 초기 공개에 포함되지 않는다. HF 모델 페이지에서 11월 26일 KST에 배포 내용을 확인했다. 가중치 최초 공개 전환 시각은 미확인이다.
- **실행:** 공식 예시는 BF16과 멀티 GPU 추론 설정을 사용한다. 활성 파라미터가 3B라고 해서 가중치 전체가 3B 크기로 적재되는 것은 아니다. Diffusers 파이프라인이 아니며, 사용자 지정 코드는 리비전을 고정한 뒤 검토해야 한다. 사용자 장비의 속도와 최소 VRAM은 미검증이다.
- **활용 예:** 비상업 연구에서 1024×1024 인포그래픽을 생성하고 제목 철자, 지정한 물체 수, 배치 오류를 따로 세어 본다. 영어·한국어 결과를 각각 평가하고, 자동 생성된 텍스트를 검증 없이 게시하지 않는다.
- **태그:** text-to-image, autoregressive, visual tokenizer, MoE, research.
