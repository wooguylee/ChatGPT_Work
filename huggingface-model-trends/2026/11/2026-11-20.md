# 2026-11-20 Hugging Face 모델 트렌드

- **관찰일:** 2026-11-20, Asia/Seoul(KST).
- **신규 소개: 3개 계열. Top Pick: Olala 1.0 mini.** 소형 로컬 모델에서 한국어 입력, 구조화 출력과 간단한 함수 호출을 평가해 볼 후보다. 이번에 함께 소개하는 두 Inworld 모델은 음성을 생성하지 않는다. 하나는 잡음을 줄이고, 다른 하나는 말이 끝났는지 판단한다.

## 1. Olala 1.0 mini: 작은 활성 규모의 혼합 언어 모델

[기반 모델 카드](https://huggingface.co/OVHaiLLM/Olala-v1.0-mini-7A1B-base)와 [지시형 카드](https://huggingface.co/OVHaiLLM/Olala-v1.0-mini-7A1B)에 따르면 36개 층 중 29개는 Mamba-3, 7개는 어텐션이며 각 층에 전문가 혼합 블록을 둔다. 개발사는 기반 모델을 12.8조 토큰으로 사전학습하고 지시형에는 지도 미세조정과 강화학습을 적용했다고 설명한다. Qwen 토크나이저의 저작권 고지가 따르지만, Qwen 가중치를 변환한 모델이라는 뜻은 아니다. Base·SFT·요약·번역 체크포인트와 GGUF·MLX는 따로 세지 않았다.

- **공개:** [OVH 사전 발표](https://corporate.ovhcloud.com/en/newsroom/news/ovh-olala-mini/) 11월 17일, 모델 카드상 정식 공개 11월 19일. 관찰은 11월 20일 KST이며 최초 HF 공개 전환 시각은 미확인이다.
- **실행:** 입력과 출력을 합쳐 32K 문맥. 카드 기준 로컬 경로는 제작자 제공 llama.cpp·MLX·vLLM 포크에 의존한다. 일반 Ollama·LM Studio나 상류 빌드의 자동 호환을 전제하지 않는다. NVIDIA vLLM 안내는 24GB 이상이며, 특정 RTX 3090의 속도나 최장 문맥 수용은 검증하지 않았다.
- **예시:** 로컬에서 합성된 한국어 문의 20건을 분류해 JSON으로 반환하게 한 뒤, 형식 유효율과 의도 분류 정확도를 따로 측정한다. 함수 호출은 외부 시스템 대신 고정 응답을 돌려주는 모의 함수로 확인한다. 한국어는 사전학습 언어지만 실사용 품질은 미검증이다.
- **태그:** 텍스트 생성, Mamba-3, MoE, 로컬 추론, 도구 호출.

## 2. Voice Isolator v1: 녹음 정리와 실시간 잡음 억제

[공식 발표](https://inworld.ai/blog/introducing-voice-isolator)는 11월 18일이다. [모델 카드](https://huggingface.co/inworld/voice-isolator)에는 주파수 대역을 나눠 시간·대역 방향 특징을 처리한 뒤 잡음을 억제하는 구조가 설명돼 있다. 오프라인판은 8초 청크 전체를 쓸 수 있고, 실시간판은 작은 미래 구간만 본다. 실시간판의 **20ms는 미래 참조 길이**이며 그 설정의 **알고리즘 지연은 카드 기준 63ms**다. 장치 처리와 오디오 입출력 지연은 별도다.

- **예시:** 같은 샘플 녹음의 원본과 오프라인 처리본을 비교하고 자음·숨소리·약한 음성이 지워지는지 확인한다. 라이브라면 전체 지연을 별도로 재고, 말소리가 겹칠 때 특정 화자만 남긴다고 가정하지 않는다.
- **제약:** 잃어버린 대역을 복원하는 모델은 아니다. 제작자 VIBE 수치는 비공개 내부 평가 세트에 기반한다. 공식 카드에 CPU 실행 경로가 있으나 한국어 녹음과 사용자 장치의 속도는 미검증이다.
- **태그:** 음성 향상, 48kHz, 잡음 억제, 실시간 오디오.

## 3. SAVA: 언제 말이 끝났는지 감지

[공식 발표](https://inworld.ai/blog/introducing-sava)는 11월 18일이다. [모델 카드](https://huggingface.co/inworld/sava)는 Mamba-2·어텐션을 섞은 공통부에 음성 활동과 턴 종료를 따로 예측하는 두 헤드를 설명한다. 40ms 단위로 두 확률을 출력하고, 애플리케이션이 시작·종료 조건을 정한다. Voice Isolator의 포트가 아니며 Haru·Sophon 같은 응답 생성형 전이중 모델도 아니다.

- **예시:** “그다음에… 잠깐만요”처럼 문장 중간에 멈춘 한국어 샘플과 진짜 문장 종료를 비교한다. 응답을 너무 일찍 시작한 비율과 종료 후 대기시간을 따로 재고, TV 음성이나 짧은 맞장구를 포함한다.
- **제약:** 개발사 자체 AMI 평가에서 200ms 안에 감지한 실제 턴 종료는 85.5%였으나, 다른 턴 데이터셋에서는 비교 모델이 앞선 경우도 있었다. 한국어 품질과 현장 지연은 미검증이며, 학습 데이터·레시피 전체는 이 배포에 포함되지 않는다.
- **태그:** VAD, 발화 종료, 스트리밍, CPU.

## 제외와 직전 7일 비교

- [RMBG-3.0](https://huggingface.co/briaai/RMBG-3.0)은 기존 RMBG-2.0과 접근이 크게 다르지만, 카드상 이미 등록한 Fibo 2.0 편집 가중치에서 직접 미세조정·증류한 모델이다. 이번에는 Fibo의 직접 파생으로 제외했다. [SenseNova-Loop-9B](https://huggingface.co/sensenova/SenseNova-Loop-9B) 역시 기존 Preview와 구분되는 별도 계열로 세지 않았다.
- [Microsoft Aion 1.0](https://huggingface.co/microsoft/Aion-1.0-Instruct-2.3B)은 Windows용 소형 모델 후보로 관찰했다. 카드에 Phi Silica 학습 데이터 확장과 Aion 구조 설명은 있지만, 이번 확인에서는 가중치 초기화 계보와 기존 세대 대비 차이까지 충분히 대조하지 못해 보류했다.
- [트렌딩 첫 페이지](https://huggingface.co/models?sort=trending), [둘째 페이지](https://huggingface.co/models?p=1&sort=trending), [최근 수정 목록](https://huggingface.co/models?sort=modified)과 제작사 자료를 대조했다. 직전 7일(11월 13~19일) 아카이브는 신규 소개 합계 6개였고, [Haru](2026-11-14.md)·[Sophon](2026-11-17.md)·[tiny-voca](2026-11-18.md)는 음성 응답·합성 쪽이었다. 오늘의 두 음성 모델은 응답을 만들기 전의 입력 처리와 타이밍에 집중한다. 이 비교는 기록된 선정 수와 용도 비교이며 순위·다운로드 증감은 확인하지 않았다. 실제 모델 실행도 하지 않았다.
