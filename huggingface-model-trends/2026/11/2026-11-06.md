## 2. ERNIE 5.5 Flash Base: 후학습 출발점을 공개한 새 기반 모델

### 이름 부재가 아니라 사전학습·구조로 판정

[공식 기술 발표](https://ernie.baidu.com/release/ernie-5-5-flash-base/)는 **33.5조 토큰, Muon, FP8 혼합 정밀도로 처음부터 사전학습**했다고 명시한다. 이번 가중치는 mid-training·post-training 이전 checkpoint다. 기존 색인의 Baidu Unlimited-OCR와 같은 개발사라는 이유로 같은 계열로 묶지 않으며, 기존 Qwen·DeepSeek·GLM 가중치의 직접 미세조정이라는 근거도 없다. 아카이브에서 ERNIE 5.5 기반 계열을 처음 소개하는 것이지 ERNIE라는 브랜드가 처음 등장했다는 뜻은 아니다.

[공식 모델 카드](https://huggingface.co/baidu/ERNIE-5.5-Flash-Base/blob/main/README.md)의 주요 구조는 다음과 같다.

- 43층 중 **37 HCA + 6 MLA-DSA**. HCA는 과거 128토큰을 한 cache entry로 압축하고, MLA-DSA는 token 수준의 sparse 참조를 담당한다.
- 첫 dense FFN 이후 42개 Multi-Router Latent MoE. 512 routed experts 중 top-10과 shared expert 1개를 사용한다.
- 4-stream mHC, attention head 간 VHA, 마지막 backbone 층을 재사용하는 ECHO와 MultiMax output head를 결합한다.

이 조합과 별도 사전학습을 선정 근거로 삼는다. FP8·[BF16 배포](https://huggingface.co/baidu/ERNIE-5.5-Flash-Base-BF16)는 한 계열이다. 다른 모델에도 있는 mHC·MoE라는 용어만으로 독창성을 주장하지 않는다.

최대 사전학습 길이 **131,072**와 추가 학습·추론 지원 **1,048,576**은 구분한다. 1M 모든 입력에서의 정확도·메모리·속도를 검증한 것은 아니다. 공식 280B/14B 표기는 추가 ECHO 규모 0.36B를 제외한다. Base 상태이므로 안전 정렬·도구 사용·대화 지시 수행이 완료된 서비스 모델로 안내하지 않는다.

**태그:** text-generation, base-model, MoE, hybrid-attention, HCA, MLA-DSA, long-context, en, zh.

### 활용 예와 평가 범위

허용 지역에서 필요한 권리를 확보한 연구자가 **동일 Base checkpoint에 서로 다른 domain adaptation/SFT 방법을 적용하고, 고정된 미공개 검증 세트로 추가 학습 효과를 비교**하는 용도가 적합하다. 한국 내 실행 예로 권하는 것은 아니다.

공식 문서의 인터페이스는 일반 chat API가 아니라 **/v1/completions**이고, Transformers 입력에는 BOS를 위해 **add_special_tokens=True**가 필요하다. [공식 배포 plugin](https://github.com/baidu/vLLM-ERNIE)과 모델 카드의 runtime 조건을 먼저 확인해야 한다. 예시 평가 입력은 비민감 합성 문장의 이어쓰기인 “Large language models are”와 고정 출력 상한 256토큰으로 시작할 수 있다. 실제 설치·추론·가입·통지·조건 수락은 하지 않았다.

제작자의 Base benchmark 표는 **개발사 자체 평가**다. 후학습된 chat 모델의 점수와 직접 순위를 만들지 않는다. 한국어 품질·최소 VRAM·실제 1M 지연은 미확인이다.

## 3. Haas ASR: 처음부터 학습한 일본어 encoder와 KDA transducer

### Parakeet 설계 재사용과 가중치 파생을 구분

[10/30 공식 개발 글 §2.3](https://third-intelligence.com/ja/posts/haas-ja-v1-release)은 encoder를 **CTC loss로 처음부터 600,000 steps 학습**한 뒤 TDT decoder를 붙여 전체 모델을 **100,000 steps** 학습했다고 설명한다. 약 46,000시간의 공개·내부 음성, 최대 30초 발화를 사용했다.

Parakeet-TDT의 FastConformer·transducer 설계와 NeMo 구현을 재사용하지만, 이 설명은 Parakeet 가중치를 일본어로 조금 미세조정했다는 계보와 다르다. 기존 등록 orukeet·Nemotron ASR의 크기 변형·직접 checkpoint 파생으로 판단하지 않는다. **Haas 자체 사전학습 계열의 첫 소개**이며 Kimi 언어 모델을 ASR로 미세조정했다고 쓰지 않는다.

[공개 config](https://huggingface.co/third-intelligence/Haas-ja-v1.0/blob/660728d39019e5e065046154beca44ac9a66a540/config.yaml)는 24-layer·hidden 1,024 FastConformer encoder, 8배 subsampling, full-context attention과 **2-layer·hidden 640 KDA prediction network**를 명시한다. [실제 decoder 구현](https://github.com/third-intelligence/Haas-ASR/blob/main/src/haas_asr/prednet.py)은 기존 NeMo LSTM stack을 pre-norm residual KDA block으로 교체하고 label embedding·joint network·decoding 알고리즘은 유지한다. 새 구조의 범위를 이 prediction network로 한정한다.

[모델 카드](https://huggingface.co/third-intelligence/Haas-ja-v1.0)의 공식 규모는 **615.8M = encoder 608.9M + prediction network 3.9M + joint network 3.0M**이다. 16kHz mono 입력과 일본어 3,072-token BPE를 사용한다. 한국어·범용 다국어 모델로 안내하지 않는다.

**태그:** automatic-speech-recognition, Japanese, FastConformer, TDT, KDA, NeMo, offline.

카드는 가중치·추론 코드 **Apache-2.0**을 명시하고 [공식 코드 LICENSE 전문](https://github.com/third-intelligence/Haas-ASR/blob/main/LICENSE)도 확인했다. HF에 별도 LICENSE 파일은 404여서 가중치 별도 원문은 독립 확인하지 못했다. 외부 구성요소의 조건·재배포 고지·입력 음성의 사용 권한은 별도로 확인한다.

[공식 실행 README](https://github.com/third-intelligence/Haas-ASR)는 Linux·NVIDIA GPU, Python 3.11+, NeMo 2.7과 CUDA/Triton 기반 KDA kernel을 요구한다. **현재 CPU·macOS는 미지원**이다. 작은 모델이라는 이유로 모든 개인 장비에서 실행된다고 안내하지 않는다.

### 활용 예: 동의받은 일본어 샘플의 고유명사·숫자 검사

코드·의존성·revision을 검토하고 공식 환경을 준비한 뒤 사용할 최소 예다. 이번 조사에서는 실행하지 않았다.

~~~python
import haas_asr

model = haas_asr.load_model("third-intelligence/Haas-ja-v1.0")
audio = haas_asr.load_audio("consented_japanese_sample.wav")
output = model.transcribe([audio])
print(output[0].text)
~~~

[공식 quickstart](https://github.com/third-intelligence/Haas-ASR#quickstart)에 맞춘 형태다. 직접 NeMo를 호출하는 경우에도 **haas_asr를 먼저 import**해야 custom decoder가 등록된다. 라이브러리가 stereo를 mono로 합치고 16kHz로 resample하므로 원본은 별도로 보존한다.

직접 만든 20초 일본어 음성에 날짜·금액·고유명사를 넣고 사람 전사와 비교한다. vocabulary boost를 켠 경우와 끈 경우를 함께 검사해 **실제로 말하지 않은 등록 단어가 삽입되는지**도 센다. 30초 초과 음성은 quiet-point chunking 경로를 따로 시험하며 경계 누락·반복을 확인한다. 화자 라벨은 별도 diarizer를 결합하는 기능이며 Haas 자체 기능으로 세지 않는다.

학습은 offline이고, 반복 재전사 데모를 native streaming 학습으로 표현하지 않는다. 카드의 CER strict **6.12%**와 처리량은 **제작자 평가**이며 같은 benchmark·normalization 조건에 한정된다. GPU가 계속 가동된다는 비용 가정을 일반 서비스 총비용으로 바꾸지 않는다. 한국어 품질·최소 VRAM·사용자 장비 지연은 미검증이다.

[Comfy-Org 변환 카드](https://huggingface.co/Comfy-Org/Idol)는 fine-tune이라고 명시한다. 현재 Idol만의 독립 구조 세대라고 소개하지 않는다. TripoSplat/DeG-VecSeq의 별도 구조·학습 근거는 있으나 Idol의 정확한 checkpoint 초기화·학습 공개는 확인하지 못해 이번 선정은 보류한다. **미등록 TripoSplat 전체를 영구 제외한다는 뜻은 아니다.**
- Ripple·Kimi-K3.1-Pro는 [어제](2026-11-05.md) 등록했다. LFM3 modality·포맷 변형, Mistral Large4, SenseNova-Loop, Unlimited-OCR-2, Nemotron Transcribe·RE-USE 등도 재소개하지 않는다. Nanbeige4.3·Spark-X2.6·MiniMax-M3.1의 이전 보류를 해제할 추가 비교는 이번에 완료하지 않았다.

제외 후보의 새 업데이트·오늘 노출을 최초 출시일로 쓰지 않는다. 위 후보의 정확한 최초 공개일·미확인 메타데이터는 추정하지 않았다.

## 5. 전주 비교와 색인 정합성

전주 같은 요일 [10/30](../10/2026-10-30.md)은 **Mistral Large4 1계열**, 오늘은 **ERNIE Base·Haas ASR 2계열**이다. 선정 주제가 대형 멀티모달 서비스 후보에서 사전학습 연구용 백본·일본어 전사로 바뀐 아카이브 비교다. 시장 수요가 두 배 늘었다거나 품질이 상승했다는 의미는 아니다.

전체 **52,976자 introduced-models.md**와 최근 [10/30](../10/2026-10-30.md)·[10/31](../10/2026-10-31.md)·[11/01](2026-11-01.md)·[11/02](2026-11-02.md)·[11/03](2026-11-03.md)·[11/04](2026-11-04.md)·[11/05](2026-11-05.md)의 전체 본문을 대조했다. **7편·6개 소개 계열은 모두 색인에 있어** 이 범위의 누락 복구 대상은 없다. 과거 전체 자료의 사실 재감사라는 뜻은 아니다.

오늘 경로는 사전 main 조회에서 404였다. 오늘 보고서를 먼저 저장하고 **main의 전체 원문 일치**를 확인한 뒤에만 최신 색인을 다시 읽어 두 계열을 추가한다. 기존 색인 전체를 보존하며 누락된 과거 날짜 보고서는 생성하지 않는다.

## 조사 범위와 한계

HF 트렌딩 [1페이지](https://huggingface.co/models?sort=trending)·[2페이지](https://huggingface.co/models?p=1&sort=trending)·[3페이지](https://huggingface.co/models?p=2&sort=trending), [최근 수정 목록](https://huggingface.co/models?sort=lastModified), 후보 공식 카드·발표·설정·코드·약관을 확인했다. 서로 다른 페이지의 캐시·갱신 시차가 있어 동일 시각 순위표로 합치지 않는다. 동일 조건의 전주 snapshot이 없어 **정확한 주간 좋아요·다운로드 증가율과 순위 상승폭은 미확인**이다.

일부 웹 본문 열람 오류는 공식 HF raw/API의 읽기 전용 조회로 보완했다. 가중치 다운로드·모델 설치·remote code 실행·benchmark 재현·GPU 측정은 하지 않았다. 공개 사실을 검증한 범위만 기록하며, 시장 전체 전수 조사나 오늘 새 계열이 두 개뿐이라는 결론은 아니다. 다른 보고서 경로·과거 날짜·예약 설정은 변경하지 않는다.
