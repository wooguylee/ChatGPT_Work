### DSpine: 가속 연구의 유용성과 신규 본체 판정은 별개

[공식 카드](https://huggingface.co/tencent/Qwen3.8-27B-DSpine-b16#usage)는 Qwen3.8-27B와 함께 쓰는 **5층·block size 16·8,192-token sliding window** draft 모델이라고 명시한다. 병렬 초안의 인접 위치 특징을 깊이 방향으로 전달한다. 독립적으로 Qwen 전체를 대체하는 2B 대화 모델로 안내하지 않는다.

SGLang 0.5.22·BF16·FA3·동시성 8과 replay 조건의 제작자 throughput은 사용자의 단일 요청 지연이나 실제 업무 완료 시간과 다르다. 본체가 이미 색인에 있으므로 [11/09 검토](2026-11-09.md)의 보조 배포 분리를 유지한다. 기술 아이디어가 새롭지 않다는 뜻은 아니다.

### HyperFlow: 압축과 포맷을 여러 신모델로 세지 않음

[공식 카드](https://huggingface.co/VideoRebirthAI/hyperflow-h3-flash#hyperflow-h3-flash-14b)는 MiniMax-H3의 compressed few-step 버전이라고 명시한다. GGUF·INT8·BF16과 입력 모드 차이를 독립 계열로 나누지 않는다. 13.7B/13.9B는 생성 transformer 범위이며 전체 파이프라인 메모리와 다르다.

카드에는 **대한민국·미국·EU·영국에서 MiniMax의 사전 허가 없는 이용이 허가되지 않는다는 지역 제한**이 명시돼 있다. 한국에서 자유롭게 다운로드·실행하라는 추천은 하지 않는다. 약관 수락·다운로드·실행도 하지 않았다. 제작자의 특정 GPU 속도를 다른 장치의 실시간 보증으로 옮기지 않는다.

### 음성 후보: 메타데이터는 확보됐지만 계보 보류를 해제하지 않음

**Mithi:** [카드](https://huggingface.co/Oomni/mithi-v1-flash#limitations)는 영어를 포함한 11개 언어·고정 2음성·24kHz mono와 Maya2-native·Kokoro·IndicBERT 구성 재사용을 밝힌다. 한국어는 목록에 없다. 공개 자동 평가·MOS가 없고 문장 간 문맥을 보지 않는 한계도 명시한다. [11/11 보고서](2026-11-11.md)의 writer 초기화·전체 학습 recipe 보류를 해소할 추가 근거를 이번에 확보하지 못했다. 오늘 config 웹 조회는 실패했으므로 새로 원문 검증했다고 쓰지 않는다.

**Woof:** [카드](https://huggingface.co/ConwayResearch/Underdog-Woof#model)는 Mimi에서 개작한 decoder와 영어 2음성 구성을 설명한다. 다운로드 40.6MB와 파라미터 약 38.24M은 다른 단위다. 비상업 조건과 회사 업무·수익형 영상 등 상업 이용의 별도 허가를 구분한다. [11/10](2026-11-10.md)에 LICENSE 전문이 확인됐다는 기록을 미확인으로 되돌리지 않지만 오늘 새 권리 해석을 확정하지는 않는다.

작은 크기·제작자의 WER 비교만으로 미확인 초기화 계보를 채우지 않는다. Mimi 재사용이 곧 Pocket-TTS 가중치 직접 파생이라는 결론도 아니다. 두 음성 후보 모두 **최초 공개일·public 전환 시각은 이번에 확정하지 못했고 관찰일은 11/15**다. 속도·청취 품질은 직접 측정하지 않았다.

### Edge0·Sophon: 변경 내용을 인정하되 선정 문턱은 유지

[Edge0 카드](https://huggingface.co/Edge0/Edge0-145B-NVFP4#architecture)는 latent MoE, D/U projection, PLE와 메모리 계층을 설명하고 Qwen3.8-Flash-Next 원천 조건을 인정한다. 이 구조 설명을 무시해 단순 파일 변환이라고 단정하지 않는다. 다만 원천 대비 초기화·핵심 재학습과 세대 단절의 충분한 대조를 완료하지 못했으므로 [11/14 보류](2026-11-14.md)를 유지한다. HF 약 5B 배지를 전체 145B와 같은 의미로 비교하지 않는다.

**Sophon-Realtime**의 [공식 Tag NOTICE](https://github.com/adventists-ai/sophon-realtime/blob/main/tag/NOTICE)는 Qwen3-VL→DuplexJev·tag adapter와 CosyVoice3 파생 경로를 명시한다. 오늘 HF 본문·raw 조회가 실패했고 E2E 구조·학습과 원천 권리 관계를 새로 확정하지 못했다. [11/12 보류](2026-11-12.md)를 유지하며 Tag 고지만으로 E2E 전체의 구조·권리를 일반화하지 않는다. 전체 파라미터·최초 공개일은 미확인이다.

## 3. 실무 활용 예: 신규 추천 대신 검증 절차

다음은 **미실행 평가 설계**다.

1. **가속기 비교:** 같은 Qwen 본체·prompt·생성 길이·동시성·decoding 조건에서 기본 실행과 DSpine을 비교한다. 초안 수락률, 첫 토큰 지연, 전체 처리시간, peak VRAM을 분리해 기록한다. tool 호출의 실제 실행 시간까지 포함했는지 명시한다.
2. **소형 TTS:** 사용 권리를 확보한 영어·인도 언어의 짧은 숫자/날짜 문장으로 원문 누락·발음 오류와 문장당 시간을 측정한다. WER과 사람의 자연스러움 평가는 나누고 정상화 설정·재시도 횟수를 고정한다. 상업 목적은 해당 모델의 별도 조건을 먼저 확인한다.
3. **오프로딩 모델:** 짧은 prompt의 tok/s만 보지 말고 긴 입력·재시작·SSD cold cache와 warm cache를 나눠 측정한다. 가중치 파일 크기·GPU cache·host RAM·총 프로세스 메모리를 별도로 기록한다.

신규 0개이므로 검증하지 않은 설치 명령·임의 API를 추가하지 않았다. 코드 설치·가중치 다운로드·추론·외부 서비스 호출은 수행하지 않았다.
