## 1. 오늘의 관찰

[HF 트렌딩 1페이지](https://huggingface.co/models?sort=trending)·[2페이지](https://huggingface.co/models?p=1&sort=trending)와 [최근 수정 목록](https://huggingface.co/models?sort=lastModified)을 확인했다. 최근 소개한 Haru·Inkling 2 Small·ZONOS3-Mini·PAN2·MNN-Pocket과 기존 Qwen·MiniMax 배포가 함께 노출됐다. 오늘은 Raon nano의 직접 증류 계보, Liquid-Codec의 기존 출시 구성요소 관계, FLUX 이미지·Comfy 배포와 Viggle LoRA를 재검토했다.

목록 노출·최근 수정은 출시 증거가 아니다. 페이지별 갱신 시차가 있으므로 정확한 동시 순위표로 합치지 않는다. 오늘 세계에 새로운 계열이 없다는 전수 조사 결론도 아니다.

### Raon nano: 구조 변화가 있어도 직접 파생을 숨기지 않음

[공식 카드의 학습 절](https://huggingface.co/KRAFTON/Raon-1-nano#training)은 Raon-1 mini preview에서 MoE-to-Dense pruning·knowledge distillation으로 출발했다고 명시한다. 3T continued pretraining과 SFT·on-policy distillation·RL도 설명한다. 이는 작은 모델의 실용성을 부정하는 근거가 아니라, 이번 자동화의 **직접 파생 제외** 조건에 해당한다는 뜻이다. [11/13 판정](2026-11-13.md)을 유지한다.

카드의 1.5B effective와 3.1B total은 다르며, total에는 1.5B per-layer embedding table이 들어간다. 18 RDA·6 MLA의 hybrid dense 구조와 262,144-token 설정을 확인했다. 설정 한도가 모든 긴 대화의 정확성을 보장하지는 않는다. 원본·GGUF·MLX·LiteRT-LM을 별도 계열로 세지 않는다. 최초 가중치 공개일은 이번에 확정하지 못했으며 오늘은 관찰일이다.

### Liquid-Codec: 독립 배포와 독립 신규 소개를 구분

[공식 카드](https://huggingface.co/LiquidAI/Liquid-Codec)는 **LFM3-Audio-2B·LFM3-Omni-2B의 audio tokenizer**라고 명시한다. causal encoder/decoder와 grouped finite scalar quantization, 24kHz mono·12.5Hz·12 codebooks/frame·1.65kbps를 설명한다. 코드북 예측의 순차 의존을 줄이는 설계는 유용하지만 이미 등록한 LFM3 출시 묶음과 별개 계열로 중복 계산하지 않는다. [11/14 기록](2026-11-14.md)을 유지한다.

카드의 처리 속도는 제작자 장치·조건의 측정이며 사용자 장비의 지연 보증이 아니다. speech용 평가를 음악·노래·환경음 품질로 확대하지 않는다. 최초 standalone 공개일은 미확인이다.

### FLUX 3 Image: Comfy 포맷과 새로운 계보를 혼동하지 않음

[원본 카드](https://huggingface.co/black-forest-labs/flux-3-image-klein)와 [Base 카드](https://huggingface.co/black-forest-labs/flux-3-image-klein-base)를 확인했다. 5.6B는 이미지 transformer이며 Qwen3-VL-4B encoder는 별도다. 최대 10개 참조와 bounding box 조건, full-scene caption 학습을 설명한다. Base는 50-step·guidance 3.5, distilled는 16-step 경로다. [Comfy 배포](https://huggingface.co/black-forest-labs/flux-3-image-klein-comfy)·FP8·NVFP4를 각각 신모델로 세지 않는다.

[BFL 출시 글](https://bfl.ai/blog/flux-3-image-klein)은 **2026-10-15** 공개와 FLUX 3의 이미지·영상·음성 공유 학습을 명시한다. [공식 연구 글](https://bfl.ai/blog/flux-3)도 같은 멀티모달 기반에서 Image·Action을 전개한다고 설명한다. [11/07의 보수적 제외](2026-11-07.md)를 뒤집을 별개 신규 계보의 충분한 근거를 이번에 확보하지 못했다. Action과 이미지 기능이 같다는 뜻은 아니다. 발표일·오늘 관찰일·HF 최초 public 전환 시각을 구분하며 마지막 항목은 미확인이다.

카드의 FLUX Kommunity 조건은 비상업 이용과 Qualifying Users의 commercial-output 예외를 구분한다. 누구에게나 무조건 자유로운 상업 사용으로 안내하지 않는다. gated 조건 수락·파일 다운로드는 하지 않았다.

### Viggle Remake: 편집 기능과 새 백본은 별개

[공식 카드](https://huggingface.co/Viggle/Viggle-Remake)는 MiniMax-H3용 LoRA와 sampler 중심의 편집 배포를 설명한다. 전신·얼굴 교체나 장면 편집 옵션, 이름 변경을 독립 새 기반 모델로 세지 않는다. [11/11의 직접 파생 제외](2026-11-11.md)를 유지한다. 가중치 규모와 기본 H3 전체 메모리는 다른 범위이므로 파일 크기를 총 파라미터·최소 VRAM으로 변환하지 않았다. 최초 공개일은 이번에 확인하지 못했다.

## 3. 실무 활용 예: 신규 추천 대신 검증 설계

다음은 **실행하지 않은 평가 설계**다. 모델·코드·라이선스 검토와 격리된 환경 준비가 선행돼야 한다.

1. **한국어 소형 도구 호출:** 비민감 가상 일정·메모에서 날짜와 인원을 추출하도록 하고, JSON 형식 성공과 실제 값의 정확도를 따로 채점한다. tool call은 기록만 하고 실제 일정 생성·파일 수정에 연결하지 않는다. 원본과 양자화판은 같은 prompt·sampling·문맥 길이로 비교한다.
2. **음성 codec:** 본인 음성의 짧은 숫자·날짜·고유명사를 encode/decode해 누락·발음 손실·복원 잡음을 듣는다. 전체 왕복 시간과 codec 계산 시간을 분리하고, speech 성능으로 노래 품질을 추정하지 않는다.
3. **이미지 편집:** 직접 만든 비민감 사물 사진에서 색상 한 곳만 바꾸고 편집 영역·비편집 영역의 변화를 따로 측정한다. box가 hard mask와 같은 보존 보증인지 가정하지 않으며 caption 확장 전후를 함께 기록한다. 타인의 얼굴·사적 이미지는 사용하지 않는다.

검증하지 않은 설치 명령·임의 API를 추가하지 않았다. 가중치 다운로드·코드 실행·추론·외부 API 호출은 수행하지 않았으며 한국어 품질·장치별 성능은 미검증이다.

오늘 경로는 main 사전 조회에서 404였다. 보고서를 먼저 저장하고 main 전체 원문 일치를 확인한 뒤 최신 색인을 재조회한다. 신규 0개·복구 0개이므로 색인은 불필요하게 변경하지 않는다. 누락된 과거 날짜 보고서·다른 작업 경로·예약 설정은 변경하지 않는다.
