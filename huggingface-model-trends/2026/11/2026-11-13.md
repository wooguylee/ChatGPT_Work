## 2. KLM: 작은 사전학습 실험을 위한 별도 백본

### 신규성·계보

[공식 KLM 1.5 카드](https://huggingface.co/MinimaLabs/KLM-1.5)는 1.1이 KeyLM-75M에서 학습을 이어간 것과 달리, **1.5는 새 구조를 처음부터 학습한 new pretrain**이라고 명시한다. 기존 색인에 KLM·KeyLM·MinimaLabs가 없으며, 기존 GPT-X3·LFM 등의 가중치를 미세조정한 모델로 설명하지 않는다. Gated DeltaNet·Block Attention Residuals 같은 공개 설계 재사용과 원천 checkpoint 직접 파생을 구분한다.

[1.6 고정 revision 카드](https://huggingface.co/MinimaLabs/KLM-1.6/blob/53226768a8957ca6f99e766f8025a96e2467537f/README.md)는 **1.5의 learning-rate decay 직전 checkpoint에서 이어서 학습**했고, decay 구간을 20B에서 100B tokens로 늘린 점 외에는 큰 변화가 없는 incremental update라고 명확히 설명한다. 따라서 KLM 1.5/1.6을 한 계열로 기록하고 두 개로 부풀리지 않는다.

공식 학습 설명은 다음 세 단계다.

1. Token-Superposition warm-up 70,000 steps. 연속 7개 token의 평균을 입력하고 다음 7개를 순서 없는 묶음으로 예측한다. 128B 원문 token을 약 18B token 수준의 연산으로 처리했다는 **제작자 설명**이며 이를 같은 의미의 next-token 학습량으로 더하지 않는다.
2. 80B tokens의 일정 learning rate next-token 학습.
3. 1.6은 100B tokens 동안 learning rate를 0으로 낮추는 decay 학습. 1.5의 20B 구간보다 길다.

MuonEq-R·AdamW, bf16, 2,048-token 문서 packing을 사용하며 문서 경계에서는 attention·recurrent state·n-gram history를 분리한다. 학습 데이터는 ClimbMix·TxT360-v2·UltraX·Cosmopedia·DCLM·수학·과학·Q&A 자료 등이다. 학습 recipe 공개가 전체 데이터 권리나 독립 재현 성공을 보증하지는 않는다.

### 구조·규모를 정확하게 읽기

[config](https://huggingface.co/MinimaLabs/KLM-1.6/blob/53226768a8957ca6f99e766f8025a96e2467537f/config.json)와 [공개 구현](https://huggingface.co/MinimaLabs/KLM-1.6/blob/53226768a8957ca6f99e766f8025a96e2467537f/modeling_klm.py)을 대조했다.

- **24층**, Gated DeltaNet-2와 full attention을 **3:1**로 혼합한다.
- hidden 512, SwiGLU 중간 폭 1,408. attention은 query 8개·KV 4개, RoPE·QK norm·output gate를 사용한다.
- **125,000 bigram·38,000 trigram**을 exact lookup하는 학습 임베딩 메모리와 Block Attention Residuals를 결합한다.
- 문맥은 **2,048 tokens**다. recurrent 구조라는 이유로 무한 문맥 품질을 주장하지 않는다.
- 카드의 어휘 약 4,100과 config의 **4,160**을 구분한다. 배포 설정값을 임의로 4,100으로 고치지 않는다.

공식 카드의 **98,975,308**은 [HF API](https://huggingface.co/api/models/MinimaLabs/KLM-1.6)의 전체 저장 원소 수와 같다. 그러나 API는 **F32 98,812,308 + I32 125,000 + I64 38,000**으로 구분한다. 구현에서 정수 두 배열은 학습 파라미터가 아닌 `register_buffer` lookup keys다. 따라서 약 99M이라고 소개하되 98,975,308을 엄밀한 고유 학습 파라미터 수로 그대로 확정하지 않는다. 전체 가중치 독립 합산·실행은 하지 않았다.

**태그:** text-generation, small-language-model, base, pretrained, hybrid, Gated-DeltaNet, n-gram-memory, English, research.

### 활용 예: 영어 짧은 이어쓰기와 후속 학습 비교

공식 코드는 CPU·GPU의 PyTorch 경로를 안내한다. 아래는 공식 카드 인터페이스에 revision을 고정한 **미실행 예시**다. `trust_remote_code=True`는 외부 Python 코드를 실행하므로 **해당 revision의 코드·의존성을 직접 검토한 격리 환경에서만** 사용한다. 이번 조사에서는 설치·모델 코드 실행·가중치 다운로드를 하지 않았다.

~~~python
from transformers import AutoTokenizer, AutoModelForCausalLM

model_id = "MinimaLabs/KLM-1.6"
revision = "53226768a8957ca6f99e766f8025a96e2467537f"
tokenizer = AutoTokenizer.from_pretrained(
    model_id, revision=revision, trust_remote_code=True
)
model = AutoModelForCausalLM.from_pretrained(
    model_id, revision=revision, trust_remote_code=True
)
inputs = tokenizer("The three primary colors are", return_tensors="pt")
outputs = model.generate(**inputs, max_new_tokens=40, do_sample=False)
print(tokenizer.decode(outputs[0], skip_special_tokens=True))
~~~

권리를 확보한 짧은 영어 설명문으로 1.5와 1.6의 같은 prompt·decoding 조건을 비교한다. 별도의 작은 domain fine-tune을 했다면 원본과 학습 후 결과의 사실 오류·반복·문장 완결성을 고정된 미공개 검증 세트로 측정한다. 공개 benchmark 문장을 다시 학습시켜 점수를 올리는 평가와 구분한다.

이 모델은 **base**이며 지시 수행·chat·안전 정렬이 완료되지 않았다. tokenizer의 chat/thinking 특수 token 존재가 그 기능 학습 완료를 뜻하지 않는다. 공식 카드도 지식이 빈약하고 사실 오류가 잦으며 **영어 전용**이라고 밝힌다. 도구 실행이나 실제 업무 결정에 바로 연결하지 않는다. 최소 RAM·한국어 품질·장치별 속도는 미검증이다.

카드의 ARC·HellaSwag·PIQA·ArithMark 점수와 소형 모델 순위는 **제작자 평가**다. 외부 peer 점수·특정 leaderboard snapshot의 비교이며 이번 조사에서 재현하지 않았다. 무조건적인 최상위 성능으로 일반화하지 않는다.

## 3. Inkling 2 Small: 단순 소형화가 아닌 구조·학습 세대 변경

[공식 HF 카드](https://huggingface.co/thinkingmachines/Inkling-2-Small)는 Thinking Machines Lab의 **594B total / 17B active**, 48층·384 experts 중 top-8 MoE, 텍스트·이미지 입력/텍스트 출력, 최대 1M 문맥을 명시한다. 음성 입력 모델로 안내하지 않는다.

기존 Inkling이 색인에 있으므로 크기·이름 변화만으로 선정할 수 없다. [Thinking Machines와 Inferact의 공동 기술 설명](https://vllm.ai/blog/2026-11-12-inkling2-small), [이전 config](https://huggingface.co/thinkingmachines/Inkling/blob/main/config.json), [신규 config](https://huggingface.co/thinkingmachines/Inkling-2-Small/blob/e242a97e271095c11bc33ddb3850d37e22917343/config.json)를 대조해 다음 주요 변경을 확인했다.

- 일반 residual stream 대신 **6층 단위 block attention residuals**를 사용한다.
- sigmoid attention output gate와 per-token attention sink를 결합한다.
- 이전 4층 hMLP 이미지 encoder 대신 **23층 ViT**를 사용한다.
- 이전 chained MTP 대신 **DSpark RNN-head** 보조 추론 경로를 도입한다.

[공식 발표](https://thinkingmachines.ai/news/inkling-2-small/)는 기존 reasoning/agent RL 분리·교사 병합과 대비한 대규모 **joint RL**도 설명한다. 카드가 사전·중간·후학습 모두 **native NVFP4**라고 밝히므로 단순 사후 4-bit 양자화만으로 만들어진 소형판이라고 쓰지 않는다. 구조·핵심 학습 경로 변경을 확인한 차세대 예외이며, NVFP4·MXFP8 배포를 별도 계열로 나누지 않는다.

공식 발표는 **11/05 최초 발표**와 **11/12 공개 가중치 배포 업데이트**를 구분한다. 이번 관찰·소개일은 **11/13 KST**다. API의 저장 원소 합계에는 packed U8와 여러 정밀도가 섞여 있어 공식 594B와 같은 의미의 파라미터 집계로 비교하지 않는다. 정확한 고유 파라미터 정수 합계는 독립 확인하지 않았다.

카드의 가중치 라이선스는 **Apache-2.0**이고 표준 약관을 연결한다. 별도 HF LICENSE 파일은 확인하지 못했다. 외부 서비스의 이용약관과 모델 가중치 조건을 구분하며 서비스 가입·조건 수락은 하지 않았다.

**태그:** image-text-to-text, multimodal, MoE, agentic-coding, tool-use, block-attention-residuals, NVFP4, long-context.

### 활용 예와 실무 도입 조건

검토할 예는 자체 제작한 웹 UI의 screenshot과 소스 코드를 입력해 **“불일치를 찾아 수정안을 만들고, 테스트·렌더링 결과로 다시 검증하라”**는 작업이다. 격리된 복사본, 제한된 파일·네트워크 권한, 시간·출력 예산을 두고 사람이 diff를 승인한 뒤 반영한다. 모델의 tool call 출력을 실제 행동의 승인으로 취급하지 않는다. 이번에 실행한 결과가 아니라 평가 설계다.

[공식 카드의 실행 안내](https://huggingface.co/thinkingmachines/Inkling-2-Small#required-hardware)는 NVFP4에 **합계 최소 500GB VRAM**(예: 2×B300 또는 4×H200), MXFP8에 **800GB**를 요구한다. “Small”과 17B active를 개인 GPU용 전체 메모리 크기로 오해하면 안 된다. SGLang·vLLM 등 해당 모델 지원 recipe와 tokenizer/chat template을 확인해야 하며 일반 모델 이름 교체만으로 실행을 보증하지 않는다.

1M 문맥의 모든 입력에 대한 정확도·지연·사용자 장비 성능과 한국어 품질은 미검증이다. 공식 benchmark·autoresearch 사례는 제작자 평가이며, 외부 도구·harness·예산 조건을 함께 읽어야 한다. 모델이 생성한 코드·평가자가 자신의 결과를 좋게 측정했는지 독립 검수한다.

## 4. 제외·보류 후보

다음 후보는 신규 소개 수와 오늘 색인 추가 대상이 아니다.

- **[Raon-1 nano](https://huggingface.co/KRAFTON/Raon-1-nano): 직접 압축·증류 파생 제외.** KRAFTON 공식 카드가 Raon-1 mini preview에서 MoE-to-Dense pruning·distillation한 계보를 명시한다. 3T continued pretraining·후학습과 per-layer embedding 변경이 있지만 엄격한 직접 파생 제외 기준에 따라 별도 신규 수로 세지 않는다. 공식 main 3.1B(+55M MTP), Apache-2.0 표기.

- **[Nex-N2.6](https://huggingface.co/nex-agi/Nex-N2.6): 직접 후학습 계보 제외.** Nex-AGI 카드가 기존 GLM-5.3-Flash 기반 약 321B FP8 배포라고 명시한다. Nex-N2.5-Pro 이후 반복 추론·tool-list 준수 개선을 설명하지만, 새 독립 구조 세대를 증명하지는 않는다. Apache-2.0 카드 표기. 내부 replay에서 100% tool 준수라는 수치를 실제 모든 환경의 보증으로 쓰지 않는다.
- **[AREX-2](https://huggingface.co/BAAI/AREX-2): 차세대 판정 보류.** BAAI의 Qwen3.8-27B 기반 27B·262K·Apache-2.0 카드다. 검증 피드백과 반복 개선 학습의 실용성은 있으나 기존 AREX·Qwen 대비 엄격한 핵심 학습법 세대 단절을 충분히 대조하지 못했다. 이름의 2와 benchmark 상승만으로 등록하지 않는다.
- **[MiniMax-H3-Image](https://huggingface.co/MiniMaxAI/MiniMax-H3-Image): 기존 H3 직접 분기 제외 유지.** audio branch 제거, 같은 H3 text encoder와 50층·33.1B DiT, 6-step 증류를 확인했다. [별도 LICENSE](https://huggingface.co/MiniMaxAI/MiniMax-H3-Image/blob/main/LICENSE)는 11/10 출시 표기와 한국·미국·EU·영국 지역 제외, hosted service·매출 조건을 둔다. 한국 내 자유로운 배포를 권하지 않는다.
- **[Arete-27B](https://huggingface.co/NousResearch/Arete-27B): 직접 SFT 제외 유지.** Qwen3.8-27B에서 구조 변경 없이 SFT만 수행했다고 공식 카드가 명시한다. 약 27B·Apache-2.0 표기이며 가치관 정렬 연구를 독립 백본으로 세지 않는다.
