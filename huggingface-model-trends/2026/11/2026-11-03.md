### 신규성의 경계

전체 색인에 RE-USE·USEMamba 계열은 없다. 기존 Nemotron ASR·Transcribe·Diarization·언어 모델과 이름을 공유하지만, 텍스트 토큰을 생성하거나 화자 라벨을 붙이는 구조가 아니다. **USEMamba 계보의 복원 모델을 이번 아카이브에서 처음 소개**하는 것이며, 모든 구성요소를 새로 발명했다거나 기존 USEMamba 대비 별도 차세대라고 주장하지 않는다. 기존 등록된 AuK 음성 foundation 계열의 가중치 파생이라는 근거도 확인되지 않았다.

[공개 모델 구현](https://huggingface.co/nvidia/NVIDIA-NemotronLabs-RE-USE/blob/main/models/generator_SEMamba_time_d4.py)은 크기·위상 입력을 합친 dense encoder, 반복 TFMambaBlock, 서로 다른 magnitude·phase decoder를 정의한다. [설정](https://huggingface.co/nvidia/NVIDIA-NemotronLabs-RE-USE/blob/main/config.json)은 30개 블록과 sampling-frequency-independent STFT를 지정한다. 기존 언어 모델에 음성 프롬프트만 넣은 파생본으로 판단하지 않는다. 정확한 초기 checkpoint 이력 전체는 미확인이므로 무조건 from-scratch 학습이라고 쓰지 않는다.

[RE-USE 논문 §3.2](https://arxiv.org/html/2603.02641v1#S3.SS2)는 기존 USEMamba를 채택했음을 명시한다. 기여는 지연을 맞춘 무반향 목표음, 데이터 품질 선별, 회귀·생성 단계를 나눈 학습 실험에 있다. 연구의 모든 실험을 배포 checkpoint 하나의 기능으로 옮기지 않는다. 같은 계열의 [laughter 배포](https://huggingface.co/nvidia/NVIDIA-NemotronLabs-RE-USE-laughter)는 웃음 보존 특화이며 별도 신규 수로 세지 않는다.

### 현재 배포와 논문을 혼동하지 않기

카드는 30층 **양방향** Mamba를 안내한다. [관련 실시간 논문](https://arxiv.org/html/2606.25621v1)은 look-ahead·early exit·decoder 전환을 다루지만, 그 논문이 링크돼 있다는 사실만으로 이 checkpoint에 모든 실시간 경로가 구현됐다고 보지 않는다. 논문도 기존 RE-USE의 비인과 구조와 실시간 후속 설계를 구분한다.

현재 [inference.py](https://huggingface.co/nvidia/NVIDIA-NemotronLabs-RE-USE/blob/main/inference.py)는 SEMamba 하나를 로드하고 STFT→크기·위상 추정→역변환을 수행한다. 별도 6층 GAN generator를 불러오는 두 단계 경로는 이 파일에 없다. HF가 자동 제시하는 MambaLMHeadModel 언어모델 예시 대신 프로젝트의 SEMamba 실행 경로를 따라야 한다.

구현 대조에서 중요한 차이도 확인했다.

- CUDA가 없으면 CPU 미지원 오류를 낸다. 9.6M이라는 작은 크기를 곧바로 CPU 실행 보증으로 해석하지 않는다.
- 카드 출력 표는 WAV이지만 현재 script는 **.flac**으로 저장한다.
- STFT 크기를 입력 sampling rate에 맞춰 바꾸고, BWE 옵션은 재표본화 경로를 켠다. bandwidth extension이 잃어버린 원음을 정확히 되찾았다는 증거는 아니다.
- 다운로드 호출에 revision이 고정돼 있지 않다. 재현 실험 전 코드·설정·가중치 revision을 함께 검토·고정해야 한다.

[실행 shell](https://huggingface.co/nvidia/NVIDIA-NemotronLabs-RE-USE/blob/main/inference.sh)의 recipe와 현재 config를 확인했다. 모델 로딩·의존성 설치·코드 실행은 하지 않았다. 공식 안내의 Linux·NVIDIA 환경을 Windows나 모든 GPU 지원으로 확대하지 않으며 최소 VRAM은 미확인이다.

## 2. 활용 예: 원본을 보존한 음성 복원 평가

다음은 직접 설계한 시험 절차이며 실제 실행 결과가 아니다. 동의를 받은 본인 음성이나 합성 음성의 비민감 샘플을 사용한다.

1. 깨끗한 말소리 10초를 원본으로 보존하고, 잡음·잔향·clipping을 각각 따로 넣은 사본을 만든다. 여러 열화를 한 번에 섞기 전에 어떤 오류를 고치는지 나누어 본다.
2. 숫자·고유명사·작은 목소리·웃음·짧은 침묵을 포함한다. 특히 다른 화자가 겹쳐 말하는 구간은 별도 테스트로 분리한다.
3. 검토한 공식 환경에서 다음과 같은 **공식 폴더 처리 경로**를 이용한다. 임의의 Python API를 만들어 쓰지 않는다.

```bash
# 공식 저장소와 의존성, 코드/revision을 검토·준비한 뒤의 예
# 짧은 mono 샘플을 noisy_audio/에 복사하고 원본은 별도 보존
sh inference.sh
# 현재 implementation의 결과는 enhanced_audio/ 아래 .flac
```

4. 음량을 맞춰 원본·열화본·복원본을 비교한다. “더 깨끗하게 들림”과 자음·숫자·웃음이 실제로 보존됐는지를 따로 기록한다.
5. 같은 ASR로 전사해 사람 정답 대비 문자 오류를 비교하되, 전사 점수 개선만으로 음질·화자 보존을 확정하지 않는다. 큰 소리로 다른 발음을 만들어낸 경우도 실패로 센다.
6. 실제 peak GPU memory·총 시간·길이별 실패를 기록한다. 긴 음성은 공식 chunk 경로를 별도로 평가하고 접합부 누락·반복을 확인한다.
7. 다화자 회의라면 다른 화자의 발언이 지워지는지 먼저 확인한다. 본 모델은 겹친 말소리에서 주 화자를 남기고 다른 화자를 억제하도록 학습됐다는 공식 주의가 있어, 회의 전체 발언 보존에 무조건 적용하면 안 된다.

공식 카드의 잡음·잔향 등 복원 범위와 약 2,500시간 데이터 설명은 제작자 보고다. **한국어 품질·음악/노래 보존·사용자 장비 지연·최소 메모리는 미검증**이다. 본 보고서는 외부 데모에 음성을 올리지 않았다.

## 3. 평가·라이선스의 한계

[논문의 실험](https://arxiv.org/html/2603.02641v1#S3)은 URGENT 조건에서 목표음 정렬·데이터 선별 효과를 분석한다. 자체 benchmark를 모든 언어·마이크·손상 정도에서의 우위로 일반화하지 않는다. 음악적 자연스러움, 말의 내용 보존, 사람 선호는 서로 다른 평가 목표다. 생성 세부를 추가하면 듣기 좋아져도 원본과 달라질 수 있다는 연구의 구분을 유지한다.

[LICENSE 전문](https://huggingface.co/nvidia/NVIDIA-NemotronLabs-RE-USE/blob/main/LICENSE)은 OpenMDW-1.1이다. 재배포 시 약관·출처 고지를 유지해야 하며, 외부 권리 확인 책임·면책과 제3자 라이브러리 고지가 있다. 카드의 상업 사용 안내를 입력 음성의 모든 권리·개인정보 동의까지 해결된다는 의미로 해석하지 않는다. 약관 수락·설치·실사용을 대신 수행하지 않았다.
