## 1. Recursive Flint: 처음부터 학습한 coding-agent MoE

**태그:** text-generation, coding, agent, tool-use, MoE, sliding-window-attention, long-context.

### 신규성

전체 인덱스에 Flint는 없었다. 제작자는 **from-scratch 사전학습 → mid-training → SFT → RL**을 명시한다. 기존 Qwen·DeepSeek·Beam의 fine-tune이라는 근거가 없으며, 별도 학습 계열로 선정했다. 49층 중 2 dense·47 MoE, 층당 routed experts 256개 중 6개와 shared expert를 사용한다. 35개 sliding-window 층과 14개 full-attention 층, QK RMSNorm·학습된 attention sink를 조합한다. 입력·출력은 텍스트이며 문맥 설정은 262,144 tokens다. 전체 학습 token 수·데이터 상세는 미확인이다. [공식 카드 원문](https://huggingface.co/RecursiveSI/flint/raw/main/README.md).

### 활용 예와 실행 제약

격리된 저장소에서 버그 원인과 회귀 테스트 초안을 만드는 실험에 적합하다. 아래는 공식 SGLang kit로 로컬 서버를 준비한 뒤 보내는 요청 예다. 이번에 서버나 모델을 실행하지 않았다.

```python
from openai import OpenAI

client = OpenAI(base_url="http://localhost:30000/v1", api_key="unused")
result = client.chat.completions.create(
    model="flint",
    messages=[{
        "role": "user",
        "content": "Write a Python interval-merging function and edge-case tests."
    }],
    max_tokens=32768,
    temperature=1.0,
    top_p=0.95,
    extra_body={"top_k": 20},
)
print(result.choices[0].message.content)
```

[공식 serving 문서](https://huggingface.co/RecursiveSI/flint/blob/main/sglang/README.md)는 **SGLang 0.5.16용 별도 kit**, 전용 parser·grammar·kernel 조건을 제시한다. 표준 Transformers modeling code가 아직 포함되지 않았다는 카드 안내를 우선하며 HF의 자동 생성 pipeline 예를 실행 보장으로 옮기지 않는다.

BF16 kit는 replica당 **141GB 이상 GPU**, B300·H200 검증 구성을 안내하며 **80GB GPU는 미지원**이다. 약 80GB 가중치 파일 크기를 VRAM 최소치로 해석하지 않는다. 이 kit의 tensor/expert parallelism·quantized KV·speculative decoding 등은 검증되지 않았다고 명시돼 있다. 별도의 GGUF·NVFP4 배포는 같은 한 계열이며 다른 runtime의 결과를 이 BF16 설정에 적용하지 않는다.

운영에서는 도구 실행을 별도 권한 검사로 제한해야 한다. 공식 문서는 tool-call 직렬화·streaming·schema 처리의 알려진 한계를 설명한다. 추론이 출력 예산을 소비하므로 답변 없이 길이 제한에 도달하는 경우도 점검한다. 서버는 인증 없이 수신할 수 있어 localhost/private network에 한정하거나 인증을 구성해야 한다. [공식 runtime 주의사항](https://huggingface.co/RecursiveSI/flint/blob/main/sglang/README.md).

카드의 자체 benchmark는 독립 재현하지 않았다. 서로 다른 harness·web retrieval 처리·정밀도의 점수를 직접 순위표로 합치지 않는다. 한국어 코딩 설명과 실제 repository 수정 성공률도 별도 검증 대상이다.

## 2. Raon-1 mini: 기존 Raon 음성 계열과 다른 언어 백본

**태그:** text-generation, Korean, multilingual, reasoning, tool-use, MoE, RDA, MLA, custom-code.

### 이름이 같아도 새 계열로 본 근거

기존 인덱스에는 **A.X-K2-Raon-Speech·Raon-OpenTTS**가 있다. [기존 A.X K2 Raon-Speech 카드](https://huggingface.co/KRAFTON/A.X-K2-Raon-Speech/raw/main/README.md)는 SK Telecom의 A.X K2 Light 언어 백본 위에 음성 encoder·codec·talker를 결합한 모델이라고 설명한다.

반면 [Raon-1 mini 공식 카드](https://huggingface.co/KRAFTON/Raon-1-mini-preview/raw/main/README.md)는 **KRAFTON이 처음부터 설계·학습한 텍스트 MoE**라고 명시한다. 25층 중 18층의 **RDA**는 Kimi Delta Attention의 erase/write gate를 분리하고, 나머지 7층은 Gated MLA를 사용한다. **Raon-mHC, 4-stream residual, NoPE**도 설명한다. 기존 음성 checkpoint의 작은 크기나 포맷 변환으로 분류할 근거가 없으며, 새 언어 기반 계열로 판정한다. 음성 입력·생성 지원을 이어받는다고 가정하지 않는다.

128 routed experts 중 6개와 shared expert가 활성화된다. 262,144-token 문맥과 7개 언어 학습을 안내하지만 전체 사전학습 token 수·데이터 구성·한국어 비중은 미확인이다. RDA의 성능 우위는 제작자의 설명이며 이번에 ablation을 재현하지 않았다.

### 활용 예

한국어 사내 문서 요약·질의 응답과 도구 선택 평가의 후보이다. 공식 카드의 호환 runtime으로 서버를 띄운 다음, 한국어 요약 요청을 보내는 예다. 민감한 실제 문서 대신 합성 자료로 먼저 점검한다.

```bash
curl http://localhost:8000/v1/chat/completions \
  -H "Content-Type: application/json" \
  -d '{
    "model": "Raon-1-mini-preview",
    "messages": [{"role":"user","content":"다음 가상 회의록에서 결정과 미결 사항을 구분해 요약해 주세요: 출시일은 미정이며, 오류 재현 테스트를 먼저 진행하기로 했습니다."}],
    "max_tokens": 8192,
    "temperature": 1.0,
    "top_p": 0.95,
    "top_k": 20,
    "presence_penalty": 1.5,
    "chat_template_kwargs": {
      "enable_thinking": true,
      "truncate_history_thinking": false
    }
  }'
```

[공식 카드의 vLLM·Transformers·llama.cpp·MLX 안내](https://huggingface.co/KRAFTON/Raon-1-mini-preview). coding·math에는 presence penalty 0을 권장하며 위 요약 예는 일반 작업용 1.5를 사용했다. vLLM은 공식 fork의 beta 경로다. 일반 upstream 안정판에서 바로 실행된다고 가정하지 않는다. Transformers 경로는 custom code 검토·revision 고정이 필요하다.

NVFP4의 RTX 5090 32GB 예시는 **32,768 context** 설정이며, 전체 262K 문맥과 동일한 메모리 조건이라고 읽으면 안 된다. 원본 MXFP8·NVFP4·GGUF·MLX·DFlash2 보조 모델을 별도 신규 가족으로 세지 않는다. 모델 접근은 gated이며 이번에는 접근 신청·약관 수락·가중치 다운로드를 하지 않았다.
