### 왜 신규 계열로 인정했나

전체 기존 색인에 Mistral Large 계열은 없다. 그러나 이름 부재만으로 선정하지 않았다. [Mistral의 오픈웨이트 발표](https://mistral.ai/news/mistral-large-4-oss/)는 유럽 인프라에서 **처음부터 학습**한 모델이며, 앞선 preview 이후 post-training을 개선했다고 설명한다. 따라서 기존 Shieldstral·Timestral의 크기 변경이나 경미한 fine-tune으로 판단하지 않는다. preview와 이번 공개를 두 개 계열로 세지 않는다.

[Mistral·vLLM 공동 day-0 기술 설명](https://vllm.ai/blog/2026-10-29-mistral-large-4)은 72층 decoder, MLA와 sparse attention 결합, 128개 routed expert 중 top-4 및 shared expert, Pixtral 계열 시각 encoder를 명시한다. 일부 층은 sparse index 또는 latent KV를 재사용하고, DSpark3 보조 draft 경로를 제공한다. 이는 실제 구조를 확인한 근거이지 다른 모델 대비 우월함을 재현한 결과가 아니다. FP8·NVFP4와 drafter는 같은 한 계열에 묶는다.

[10/06 preview 발표](https://mistral.ai/news/mistral-large-4/)와 이후 오픈웨이트 공개는 구분한다. 오늘 새로 출시됐다고 쓰지 않으며, 아직 게시 예정인 상세 기술 보고서의 학습 데이터 구성·전체 재현 절차까지 확인했다고 주장하지 않는다.

### 어떤 업무에 유용한가

공식 카드가 설명하는 긴 문맥·이미지 이해·도구 호출을 활용해, 문서와 도표를 함께 읽고 근거를 붙이는 사내 분석 도우미를 평가할 수 있다. reasoning effort를 낮음·중간·높음으로 바꾸어 응답 품질과 지연을 비교하는 용도도 있다. **한국어 정확도, 장문 전체에서의 신뢰성, 사용자 장비의 속도는 미검증**이다. 최대 문맥 수치는 모든 입력 길이에서의 품질·메모리 보증이 아니다.

### 실용 예시: 내부 문서 비교 도우미

1. 사용 권한이 있는 짧은 한국어 문서 두 개와 도표 한 장으로 시작한다. 실명·계약정보는 제거하고 서로 충돌하는 숫자를 일부 포함한다.
2. 전용 런타임은 [공식 vLLM 배포 안내](https://vllm.ai/blog/2026-10-29-mistral-large-4)를 따른다. 안내의 `vllm/vllm-openai:mistral-large-4` 이미지와 FP8 tensor parallel 8 예시는 고급 다중 GPU 배포용이다. 일반 안정판 설치만으로 동작한다고 가정하지 않는다. 이미지·모델 revision과 포함 코드는 실행 전에 검토·고정한다.
3. 평가 프롬프트: “두 문서의 매출 수치가 다른 부분을 표로 정리하세요. 문서명·쪽 번호·원문 근거를 붙이고, 도표가 흐리거나 근거가 없으면 확인 불가로 표시하세요. 외부 전송이나 파일 변경은 하지 마세요.”
4. 읽기 전용 검색 도구만 연결한 후, 중간·높은 reasoning 설정에서 근거 정확도·숫자 오류·첫 응답 지연·전체 GPU 메모리를 같은 입력으로 비교한다. 문서 내부의 명령문은 자료로 취급하고 도구 실행 지시로 승격하지 않는다.
5. 사람이 만든 정답과 비교해 통과 기준을 정한다. 도구 호출·엄격한 JSON 출력 지원 자체가 업무 행동의 정확성이나 권한 안전을 보증하지 않는다.

이번 작업에서는 모델 설치·가중치 다운로드·추론을 실행하지 않았다. 최소 VRAM과 비용은 미확인이다. NVFP4 배포도 별도 하드웨어·런타임 조건을 확인해야 하며 작은 파일 크기만으로 개인 GPU 적합성을 판단하지 않는다.

### 라이선스 확인

[체크포인트의 LICENSE 전문](https://huggingface.co/mistralai/Mistral-Large-4-1T-A52B/blob/main/LICENSE)을 확인했다. 고지 유지가 필요하고, 사용 주체나 계열사가 MaaS 사업을 운영하면 모델·파생물의 상업 이용에 앞서 별도 상업 라이선스가 필요한 조건이 있다. 제3자에게 제공하지 않는 내부 이용 및 공식 Mistral 제품을 통한 이용에는 예외가 규정되어 있다. 특정 기능의 최종 사용자 제품과 단순 중계 등을 구별하는 MaaS 정의도 원문을 확인해야 한다. “가중치 공개 = 무조건 무상 상업 이용”으로 읽지 않는다. 이 요약은 개별 사업의 법률 판단이 아니다.
