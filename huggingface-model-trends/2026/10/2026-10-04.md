## 1. Aleph Alpha Kolibri-1

**태그:** text-generation, reasoning, MoE, long-context, tool-calling, German, English.

독일어·영어의 장문 추론과 도구 호출을 겨냥한 50층 MoE다. SWA:GQA 4:1 혼합 attention, 384 experts 중 6 routed + 1 shared expert, Muon과 Exact Quantile Balancing을 사용한다. 공식 카드는 20T-token 사전학습, 3.44T mid-training, 201B long-context 학습을 구분해 공개한다. 기존 인덱스 모델의 재양자화나 이름 변경으로 소개하는 것이 아니다. 같은 Kolibri-1의 BF16·FP8·GGUF 배포는 모두 한 계열이다. [공식 카드](https://huggingface.co/Aleph-Alpha/Kolibri-1).

**문맥 길이 주의:** native 학습 길이는 262,144 tokens이며 개발사는 1,048,576까지 검증했다고 설명한다. 복잡한 작업과 효율적인 serving에는 262,144 이하를 권장한다. “native 1M 학습”이라고 표현하면 부정확하다. FP8 가중치만 약 78GB이고, KV cache와 실행 메모리가 추가된다. active 3.46B가 전체 모델의 메모리 크기를 뜻하지 않는다.

**활용 예:** 독일어·영어 사내 문서를 검색해 근거를 종합하는 RAG assistant, 긴 문서의 질의응답, 사람이 결과를 검토하는 tool-calling workflow. 한국어 특화 성능은 확인하지 않았다.

공식 카드의 실행 경로는 `aleph-alpha-inference>=1`이 제공하는 vLLM plugin이다. 설치 후 다음 serving 구성을 사용하고 OpenAI-compatible chat API로 질의할 수 있다. 아래는 공식 사용법에 따른 예시이며 이번 조사에서는 실행·성능 재현을 하지 않았다.

```bash
vllm serve Aleph-Alpha/Kolibri-1 --kv-cache-dtype fp8 \
  --reasoning-parser kolibri1 \
  --tool-call-parser kolibri1 \
  --enable-auto-tool-choice
```

**라이선스·평가:** Apache-2.0 적용 범위는 저장소에 공개한 가중치·설정이며, 카드가 별도로 유보하는 미포함 코드·아키텍처·학습법 등에 자동 확장되지 않는다. 공개 benchmark는 **개발사 자체 평가**다. 본 보고서는 서로 다른 모델의 평가 설정을 동등하게 취급하거나 전면적인 최고 성능을 주장하지 않는다. 도구 실행에는 권한 제한·출력 검증·사람의 검토가 필요하다. [모델 설명·사용법·라이선스 범위](https://huggingface.co/Aleph-Alpha/Kolibri-1#license-and-terms).

## 2. well9472 Nanosaur2-670M

**태그:** text-to-image, illustration, DiT, rectified-flow, ComfyUI, small-model research.

670M DiT에 frozen Gemma-3-270M text encoder와 129M DINOv2 기반 semantic VAE를 결합한다. SPRINT sparse middle blocks, x-prediction/v-loss, path-drop guidance와 표현공간 기반 VAE 학습이 특징이다. 제작자가 4M illustration 이미지에서 base training과 aesthetic tuning을 설명하며, 기존 Anima·Qwen-Image·Supra2-IMG 가중치의 단순 LoRA/포맷 변환으로 표시하지 않는다. 동결한 text encoder를 쓰더라도 별도 이미지 생성 backbone·VAE 학습을 갖춰 신규 계열로 판정했다. [제작자 카드](https://huggingface.co/well9472/Nanosaur2-670M).

**활용 예:** 저비용 일러스트 생성 학습법 연구, ComfyUI에서 짧은 묘사로 1024 해상도 이미지를 생성하는 실험. 카드의 연구용 경고처럼 상용 대형 모델 수준의 세부 묘사나 캐릭터 지식을 기대해서는 안 된다.

**실행 예:** 제공 custom node를 ComfyUI에 추가하고 diffusion/text-encoder/VAE 세 파일을 각각 해당 model 폴더에 넣은 뒤 `nanosaur2_workflow.json`을 불러온다. 시작 설정은 Euler simple, 50 steps, CFG 4, 1024 aspect buckets다. 예시 프롬프트는 “a small observatory on a green hill at sunrise, watercolor illustration”. custom node는 실행 전 코드를 검토한다.

카드는 MIT를 표시하지만 Gemma·DINO 구성요소의 적용 조건도 별도 확인해야 한다. 제작자의 총 학습비 $600 주장은 **자체 보고**이며 재현한 비용·이미지 품질 benchmark가 아니다. [설치·학습·제약](https://huggingface.co/well9472/Nanosaur2-670M#model-and-training).
