## 1. 신규 계열 판정: 동결 ASR 위의 별도 recurrent policy

기존 인덱스에는 **NVIDIA Nemotron 3.5 ASR Streaming**과 **NineNineSix Gepard**가 있다. TYGER에 들어 있는 ASR을 다시 소개하지 않으며, Gepard의 크기 변형이나 새 TTS로도 분류하지 않는다.

[실제 controller 구현](https://github.com/nineninesix-ai/tyger-s2s/blob/main/app/plugins/ears/tyger/controller.py)은 다음 연산 경로를 갖는다.

- 사용자 microphone과 에이전트 playback의 **서로 다른 두 1,024차원 음성 feature**를 각자 768차원으로 projection한다.
- 사용자 음량과 이전 앱 상태의 embedding을 합친 뒤, **3-layer·width-768 causal GRU**가 대화별 상태를 누적한다.
- listen/hold/speak/backchannel의 상태와 hazard·yield(끼어들기 시 양보)·backchannel·endpoint 확률을 별도 head로 출력한다.

따라서 전사 결과의 문체를 바꾸는 SFT나 기존 가중치의 양자화 배포와 구분되는 **새 입력 결합·시간 상태·행동 출력 경로**가 있다. 9KiB는 GRU의 대화별 hidden state이며 ASR·audio buffer·전체 서비스 메모리를 포함하지 않는다. 이전 상태 입력도 모델이 직전에 예측한 상태가 아니라 앱의 실제 경청/발화 상태다. [코드와 상태 계약](https://github.com/nineninesix-ai/tyger-s2s/blob/main/app/plugins/ears/tyger/controller.py).

공식 카드는 **GRU·입력층·출력 head를 Open Yap 1K v1.0에서 처음부터 학습하고 Nemotron은 동결**했다고 명시한다. train/dev/test는 1,395/107/100개 대화이며, 발화 시점에서 자동 라벨을 만든 단일 seed 학습이다. 이 별도 학습된 턴 정책을 한 신규 계열로 인정한다. **652M 전체를 from-scratch 학습했다는 뜻은 아니다.** [학습 고지](https://huggingface.co/nineninesix/tyger), [원천 구성요소 NOTICE](https://huggingface.co/nineninesix/tyger/raw/main/NOTICE.md).

## 2. 활용 예와 실행 경로

음성 상담·영어 회화 앱에서 사용자의 문장 중간 쉼을 기다리고, 사용자가 끼어들면 재생을 멈추며, 맞장구 타이밍을 실험하는 후보이다. 입력은 시간 정렬된 **16kHz mono 음성 두 채널**이다. TYGER 가중치만으로 답변 문장이나 합성 음성이 만들어지는 것은 아니며, 전체 앱에는 별도 LLM과 TTS가 필요하다. [모델의 역할](https://huggingface.co/nineninesix/tyger).

공식 **tyger-s2s**의 설치·모델 접근·환경 설정을 완료한 뒤 사용하는 실행 예는 다음과 같다. 이번에는 실행하지 않았다.

```bash
# 공식 tyger-s2s checkout과 실행 환경을 먼저 준비한 경우
./run.sh
# 브라우저에서 http://localhost:7860 열기
```

시험에서는 동의받은 영어 발화로 “문장 중간 멈춤 → 이어 말하기”, “에이전트 발화 중 끼어들기”, “배경 소음만 존재”를 나누어 확인한다. 앱의 endpoint·barge-in·backchannel threshold를 조절하며 **응답 시작 지연과 조기 끼어들기·잘못된 중단율을 함께 기록**하는 방식이 적절하다. [공식 실행·설정 안내](https://github.com/nineninesix-ai/tyger-s2s#settings).

공식 client가 microphone과 playback의 시간 관계를 맞춘다. 에이전트 음성을 다른 재생 경로로 보내면 echo를 사용자 발화로 잘못 처리할 수 있다. 기본 전체 앱은 Gemma·VoxCPM2 및 선택적 온라인 expert를 결합하므로, **TYGER 자체의 요구량과 전체 앱의 GPU·디스크·외부 API 전송을 분리**해 확인해야 한다. 온라인 모델을 활성화하면 대화 텍스트가 해당 서비스로 전달될 수 있다. [client 계약·Privacy](https://github.com/nineninesix-ai/tyger-s2s).

### 성능 수치를 읽을 때

공개 평가는 **제작자의 offline 진단**이다. endpoint 중앙값은 실제 endpoint가 발생한 사례에 조건부인 수치다. Open Yap 테스트에서 endpoint 중앙 지연 252.5ms와 함께 **조기 끼어들기 29.90%, 1.2초 내 endpoint 누락 7.40%**를 보고한다. 빠른 중앙값만으로 자연스러운 실제 대화가 검증됐다고 해석하면 안 된다. Full-Duplex-Bench도 silent-agent channel의 변형된 v1.0 CANDOR replay이며 공식 full-agent 점수가 아니다. [평가와 한계](https://huggingface.co/nineninesix/tyger).

현재 [engine 구현](https://github.com/nineninesix-ai/tyger-s2s/blob/main/app/plugins/ears/tyger/engine.py)은 320ms hop으로 최근 8초 창을 재인코딩한다. 80ms feature frame이나 GRU 연산만으로 전체 응답 지연을 대신할 수 없다.

GRU만 측정한 약 0.805ms/frame에는 음성 대기·Nemotron 연산이 제외된다. 영어 밖의 품질, 새로운 ASR 오류율, 실제 microphone 환경과 앱 기본 threshold의 품질은 검증된 것으로 소개하지 않는다. 카드에 연결된 arXiv 논문들은 관련 연구 참고문헌이며 TYGER 자체 논문으로 잘못 인용하지 않는다. [평가 조건](https://huggingface.co/nineninesix/tyger).

## 4. AuroraIMG-6M: 전 구성요소를 새로 학습한 초소형 이미지 생성

**개발 주체:** AuroraAI Research. **태그:** text-to-image, latent-flow-matching, rectified-flow, tiny-model, from-scratch, English. 기존 인덱스에 없으며, 공식 카드는 **text encoder·U-Net·VAE 모두 처음부터 학습**했고 사전학습 구성요소를 사용하지 않았다고 명시한다. 다른 대형 모델의 양자화·LoRA·증류 소형본이라는 근거는 없다. [공식 카드](https://huggingface.co/AuroraAI-Research/AuroraIMG-6M).

[실제 구현](https://huggingface.co/AuroraAI-Research/AuroraIMG-6M/blob/main/pipeline.py)과 [config](https://huggingface.co/AuroraAI-Research/AuroraIMG-6M/raw/main/config.json)를 대조했다.

- 4-layer·width-128·4-head RoPE text encoder와 4,096-token BPE를 사용한다. 영어 입력을 소문자 처리하고 본문 62 tokens에 special tokens를 붙인다.
- 16×16·8×8·4×4 해상도의 U-Net에 self/cross attention·AdaLN-Zero 시간 조건을 적용하고, 8×16×16 latent에서 **64×64 RGB** 이미지를 복원한다.
- CC12M의 **9,882,283개 학습 pair**와 별도 50,000 holdout을 사용한다. VAE는 25,000 steps, text encoder+denoiser는 flow matching·Muon/AdamW로 300,000 steps, batch 2,048을 명시한다. 약 614M sample 노출은 반복 epoch를 포함하므로 고유 데이터 614M쌍으로 쓰지 않는다.

[제작자 final_report.json](https://huggingface.co/AuroraAI-Research/AuroraIMG-6M/raw/main/final_report.json)의 정확한 합계는 **6,822,747 parameters**다. config의 6,820,000 및 카드의 6.82M는 반올림 표기다. 가중치를 직접 로드해 재계산한 수는 아니다.

**활용 예:** 작은 생성 모델의 구조·CFG 영향을 공부할 때, 공식 Diffusers custom pipeline을 검토한 환경에서 “a sunset over the ocean” 같은 짧은 영어 prompt를 **50 Euler steps·guidance 6.0**으로 생성해 볼 수 있다. 아래는 이미 공식 pipeline을 로드한 경우의 문서 기반 호출 예이며 실행 검증하지 않았다. [공식 실행 안내](https://huggingface.co/AuroraAI-Research/AuroraIMG-6M), [호출 구현](https://huggingface.co/AuroraAI-Research/AuroraIMG-6M/blob/main/pipeline.py).

```python
image = pipe(
    prompt="a sunset over the ocean",
    num_inference_steps=50,
    guidance_scale=6.0,
).images[0]
```

공식 로딩 예의 custom pipeline은 원격 Python 코드를 사용한다. 실제 실행 전 코드를 검토하고 확인한 revision을 고정해야 한다. **64×64 실험 모델**로, 정교한 얼굴·손·문자·개수·위치 지시를 기대하는 제작 도구로 추천하지 않는다. 카드의 GenEval 0.1387은 제작자 측 미검증 보고값이다. [결과 파일](https://huggingface.co/AuroraAI-Research/AuroraIMG-6M/raw/main/final_report.json)의 CC12M holdout 10,000장 FID 33.01도 64px·CFG 6 조건이며 고해상도 모델의 다른 protocol과 직접 비교할 수 없다.

**라이선스:** 카드 metadata는 Apache-2.0을 표시하지만 파일 목록에 별도 LICENSE는 확인되지 않았다. 학습 이미지의 권리나 생성물 사용 적합성이 자동 보장되는 것은 아니다. HF [metadata](https://huggingface.co/api/models/AuroraAI-Research/AuroraIMG-6M)상 생성은 **10/11 11:42:15 UTC = 20:42:15 KST**, 최근 수정은 **10/11 19:02:56 UTC = 10/12 04:02:56 KST**이고 [최신 commit](https://huggingface.co/AuroraAI-Research/AuroraIMG-6M/commit/3d66743c3139d034b832a670d067221f5d544bbb)은 README 수정이다. 최초 대외 출시일은 미확인이다. **오늘 발견했다고 오늘 출시한 모델로 쓰지 않는다.** 09:06 KST 전후 API 관찰치는 **39 likes·165 월간 downloads**이며 전주 대비 증가량은 미확인이다.

- **[Phonon-2](https://huggingface.co/FermionResearch/Phonon-2):** Fermion Research, Parakeet TDT 0.6B v3 계보, 가중치 CC BY 4.0·코드 Apache-2.0. [공식 NOTICE](https://huggingface.co/FermionResearch/Phonon-2/blob/main/NOTICE)는 encoder linear weight를 다섯 값으로 재학습·양자화하고 나머지를 int6로 저장하며 FastConformer·TDT·tokenizer를 유지한다고 밝힌다. 기존 Phonon-1과 원천 백본은 다르지만, **Parakeet의 직접 QAT·압축 배포**를 새로운 ASR 구조 세대로 소개하지 않는다. CoreML·C·GGUF 포팅도 별도 계열이 아니다.
- **[Hy-Memory-30B-A3B](https://huggingface.co/tencent/Hy-Memory-30B-A3B):** Tencent, 약 30B/3B active, Apache-2.0. [논문 §1·§4.2](https://arxiv.org/html/2610.22196v1)는 기존 Hy3 instruction checkpoint와 외부 memory framework를 유지하고 memory writer를 OPD·chunk-level RL로 후학습한다고 설명한다. [10/17](2026-10-17.md)의 직접 task adaptation 제외를 유지한다. TYGER의 별도 recurrent network를 처음부터 학습한 경우와 구분한다.
- **FLUX 3 Image Klein:** [공식 발표](https://bfl.ai/blog/flux-3-image-klein)는 10/15 공개한 5.6B 이미지 생성·편집 모델이며, 기존 Action 다음의 같은 FLUX 3 계열 배포라고 설명한다. 현재 카드·공개 코드를 다시 확인했지만 [10/16](2026-10-16.md)의 독립 차세대 구조·학습 계보 보류를 해제할 근거는 확보하지 못했다. 높은 노출과 base/distilled·ComfyUI·FP8/NVFP4 배포 수로 신규성을 대신하지 않는다.
- **[OrcaCyber-Nano-1.0](https://huggingface.co/orcarouter/OrcaCyber-Nano-1.0):** 트렌딩 목록의 존재만 확인했다. 공식 카드 열람이 실패하고 raw README 요청도 HTTP 401이어서 접근을 더 시도하지 않았다. 정확한 파라미터·라이선스·학습 계보를 이름으로 추정하지 않고 보류한다. AuroraIMG-6M는 공개 raw 카드·설정·코드·결과 파일의 정상 열람으로 근거를 확보해 위에서 별도로 소개했다.
- **Dory1.0·ALoDLM**, Beam·MOSS-Image·Timestral과 그 크기·SFT·양자화·포맷 변형은 [10/18](2026-10-18.md)·[10/17](2026-10-17.md)에 이미 소개했다. Qwen·Gemma·MiniMax·Nemotron·LFM2.5·MiniCPM 등의 직접 파생본도 전체 인덱스에 따라 제외했다. 기존 d3·THX·Ling-3.1 등 보류 후보는 추가 근거 없이 새로 등록하지 않는다.

## 6. 전주 비교와 인덱스 감사

- 전주 같은 요일 [2026-10-12](2026-10-12.md)은 **Vela 2.0 한 계열**, 오늘은 **TYGER·AuroraIMG-6M 두 계열**이다. 당시 텍스트 라우팅·span 추출에서 오늘은 양방향 음성 흐름의 발화 타이밍 판단과 초소형 이미지 생성으로 선정 주제가 달라졌다. 이는 아카이브 선정 수·주제 비교이며 시장 전체의 성장이나 동등 조건 성능 비교가 아니다.
- main의 [10/12](2026-10-12.md)·[10/13](2026-10-13.md)·[10/14](2026-10-14.md)·[10/15](2026-10-15.md)·[10/16](2026-10-16.md)·[10/17](2026-10-17.md)·[10/18](2026-10-18.md) **전체 본문**과 **전체 40,116자 introduced-models.md**를 대조했다. **1+2+2+1+4+3+2=15개 소개 계열 모두 등록**돼 이 범위에서 누락 복구 대상은 없다. 과거 전체 보고서를 오늘 다시 전수 감사했다는 뜻은 아니다.
- 사전 main 전체 tree에는 기존 일일 보고서 **75개**가 있고 오늘 경로는 없었다. 개별 경로 조회도 404였다. 오늘 보고서만 작성하고 빠진 과거 날짜를 소급 생성하지 않는다.
- 보고서를 먼저 저장하고 **main의 범위 제한 없는 전체 본문 일치**를 확인한 뒤 최신 인덱스를 다시 읽어 이전 내용을 모두 보존하며 TYGER와 AuroraIMG-6M 두 계열만 추가한다. 게시 검증 결과는 확인 후 기록한다.

## 결론과 조사 한계

**Top Pick: TYGER.** 음성 에이전트의 턴 제어를 별도 모델로 실험할 수 있는 공개 연구 후보이다. 새로 학습한 부분의 범위가 명확하다는 점을 선정 근거로 삼았으며, 공개된 조기 끼어들기·누락률을 고려하면 그대로 상용 품질이 보장되는 선택은 아니다. AuroraIMG-6M는 전 구성요소를 직접 학습한 작은 이미지 생성 구조를 살펴보는 교육·연구 후보로 의미가 있으며, 일반 이미지 제작 품질과는 구분한다.

확인한 목록: [트렌딩 1페이지](https://huggingface.co/models?sort=trending), [2페이지](https://huggingface.co/models?p=1&sort=trending), [3페이지](https://huggingface.co/models?p=2&sort=trending), [4페이지](https://huggingface.co/models?p=3&sort=trending), [5페이지](https://huggingface.co/models?p=4&sort=trending). 페이지별 캐시·경계 중복 때문에 동시에 측정한 150개 고유 모델 순위표라고 주장하지 않는다. 일부 HF 화면 열람은 실패했으나 정상 공개된 raw 파일·metadata·공식 GitHub 구현으로 근거를 교차 확인했다. 접근 거부가 확인된 후보는 보류했다.

**모델 설치·실행, 가중치 다운로드, benchmark 재현, 메모리·지연시간 측정은 수행하지 않았다.** 활용 예는 문서 기반 제안이며 한국어 품질·업무 적합성·개별 사업의 라이선스 적합성을 보증하지 않는다.
