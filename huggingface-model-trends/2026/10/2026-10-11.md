## 1. 관심 후보 재검토: 선정하지 않은 이유

아래는 **보류·제외 근거를 공개하기 위한 검토 기록**이며 신규 소개 목록이 아니다. 관련 모델의 규모·라이선스·활용 가능성이 확인돼도 계열 신규성 조건을 자동으로 충족하지 않는다.

### Cloudflare Clef-Omni: 오디오 입력 확장은 확인, 별도 세대 판정은 보류

- **개발 주체:** Cloudflare.
- **규모:** 공식 30B-A3B MoE backbone. HF 저장소 tensor 집계는 35,259,818,545이며, 저장소에는 실행 loader가 사용하지 않는 talker·code2wav 가중치도 들어 있다. 따라서 이 집계를 활성 파라미터나 실제 로딩 크기로 쓰지 않는다.
- **라이선스:** Apache-2.0.
- **태그:** multimodal, audio, video, typed-decision, joint-schema-head, MoE.
- **활용 예:** 음성 통화와 영상에서 정해진 질문의 선택지별 확률을 구하는 사전 분류. 자유 문장 설명이나 음성 생성 모델로 사용하지 않는다.

공식 카드는 **Qwen3-Omni-30B-A3B-Instruct의 thinker·vision/audio encoders를 사용하는 post-training 모델**로 명시한다. 기존 [Clef](https://huggingface.co/Cloudflare/clef)의 state→joint schema head→선택지별 확률이라는 핵심 인터페이스를 유지하면서 오디오 입력을 지원한다. 입력 범위와 backbone은 실제로 달라졌으므로 단순 크기 변형이라고 단정하지 않는다. 다만 이번에 확인한 자료만으로 기존 Clef 계열의 직접 적응을 넘어서는 독립적 세대 전환·새 핵심 학습법을 충분히 검증하지 못해 **별도 신규 계열 예외는 보류**한다.

제작자는 BF16 backbone에 약 64GB GPU 메모리, H200 테스트 환경을 안내한다. 자체 Decision Index 평가를 외부 재현 결과로 간주하지 않는다. 음성 출력용 가중치가 포함됐다는 사실을 음성 생성 지원으로 해석해서도 안 된다. [공식 카드 원문](https://huggingface.co/Cloudflare/clef-omni/raw/main/README.md), [공식 metadata](https://huggingface.co/api/models/Cloudflare/clef-omni).

### Interfaze 1 Lite: 여러 기존 모델을 묶은 실행 시스템

- **개발 주체:** Interfaze.
- **규모:** Qwen3.8 27B 기반 reasoning core와 여러 specialist의 묶음. 전체 고유 파라미터 합계는 미확인.
- **라이선스:** 카드의 별도 Interfaze 라이선스; 구성요소의 원래 조건도 확인해야 한다.
- **태그:** mixture-of-architectures, OCR, ASR, diarization, segmentation, forecasting, structured-output.
- **활용 예:** 문서 OCR 결과와 음성 전사를 모아 질의에 답하는 로컬 전처리·도구 호출 시스템.

공식 카드 자체가 **하나의 network가 아니라 reasoning core와 tool call로 연결한 specialists**라고 설명한다. Qwen3.8, Chandra OCR 2, Whisper large-v3-turbo, pyannote, SAM 2.1, Llama Guard 3, TimesFM 2.5, PaddleOCR 등의 사용을 명시한다. 이런 결합은 배포 도구로 유용할 수 있으나, 이를 별도 공동학습 foundation model이나 새로운 체크포인트 계열로 확정할 근거는 이번 자료에서 확인하지 못했다. 기존 모델 묶음을 신규 모델 수로 세지 않는다.

공식 `model.ocr("invoice.pdf")`나 `model.transcribe("call.wav", by_speaker=True)`는 활용 경로의 예다. 이번 조사에서 실행하지 않았다. 카드가 안내하는 80GB GPU·지연 로딩 조건과 Transformers 경로의 느린 문서 처리도 별도로 검증해야 한다. [공식 카드 원문](https://huggingface.co/interfaze-ai/interfaze-1-lite/raw/main/README.md), [metadata](https://huggingface.co/api/models/interfaze-ai/interfaze-1-lite).

### KittenTTS 2: 기능은 구체적이나 학습 계보는 계속 보류

- **개발 주체:** 배포 KittenML; 라이선스 주체 Stellon Labs.
- **규모:** 카드상 speech LM 1.7B, decoder·speaker model 별도. 전체 합계 미확인.
- **라이선스:** Stellon Labs Community License. 카드상 연매출 또는 누적 투자금이 USD 1,000,000을 넘으면 별도 상업 라이선스가 필요하며 attribution 조건도 있다.
- **태그:** text-to-speech, S3-codec, voice-cloning, multilingual, ternary.
- **활용 예:** 사용 권한이 있는 본인의 5~30초 음성을 참고로 문장을 읽는 TTS 실험. 감정 제어는 beta이며 결과가 보장되지 않는다.

공식 카드와 설정에서 S3 codec token 생성, 24kHz 복호화, speaker conditioning과 `Qwen3ForCausalLM` 구조를 확인했다. **설정의 architecture 이름만으로 실제 초기 가중치 계보를 확정할 수는 없다.** 공개 자료에서 원래 LM 가중치·사전학습·음성 적응 과정을 충분히 확인하지 못해 10/10의 보류를 유지한다. packed·emb4·full은 같은 가중치의 포장·양자화 선택이며 각각 별도 신규 모델이 아니다.

비영어 텍스트에서는 영어 중심 normalizer 때문에 `normalize=False`를 쓰라는 제작자 안내가 있다. 지원 언어별·한국어 품질은 검증하지 않았다. [공식 카드 원문](https://huggingface.co/KittenML/kitten-tts-2/raw/main/README.md), [LM 설정](https://huggingface.co/KittenML/kitten-tts-2/raw/main/lm/config.json), [전체 구성](https://huggingface.co/KittenML/kitten-tts-2/raw/main/config.json).
