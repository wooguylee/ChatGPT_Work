### 신규성 판정: 이름이나 성능표가 아니라 실행 구조

[공식 구조 설명](https://github.com/OpenSenseNova/SenseNova-Loop#model-architecture)은 32개 고유 decoder 층 중 **4–27번의 24개 층을 같은 가중치로 두 번 실행**한다고 명시한다. 전체 실행 깊이는 56층이다. 반복 구간에는 두 residual stream과 학습된 mHC read/mix/write 경로, 20회 Sinkhorn 정규화가 들어간다. 단순히 출력 토큰을 더 생성하는 추론 프롬프트나 가중치를 복제한 크기 확장이 아니다.

[공식 loop 설정](https://github.com/OpenSenseNova/torchtitan/blob/main/examples/train/SenseNova-Loop-9B-Preview/mhc2_loop2.json)의 start=4, end=28, eval_count=2와 [학습 launcher](https://github.com/OpenSenseNova/torchtitan/blob/main/examples/train/SenseNova-Loop-9B-Preview/mhc2_loop2_titan.sh)의 mHC 2-stream 설정도 대조했다. 이 새로운 반복·잔차 연산 그래프를 **주요 구조 변경 예외**로 인정한다. 같은 구조의 양자화·포맷·크기 변형과 보조 draft model은 별도 신규 계열로 세지 않는다.

계보를 독립 from-scratch로 포장하지 않는다. [공식 학습 문서](https://github.com/OpenSenseNova/torchtitan/blob/main/examples/train/SenseNova-Loop-9B-Preview/README.md)는 Qwen35Encoder와 호환 Qwen3.5-9B MTP checkpoint를 명시한다. [Qwen3.5-9B 설정](https://huggingface.co/Qwen/Qwen3.5-9B/raw/main/config.json)에도 32층·3 linear/1 full attention·동일 hidden/vocabulary 차원이 있으므로 **hybrid attention이나 256K 자체를 새 발명으로 세지 않는다**. 출시 가중치의 정확한 초기화·전체 사전학습 데이터와 학습량은 미확인이다. 단순 Qwen 도메인 미세조정이라는 이유가 아니라 공개된 loop/mHC 구조 차이로만 선정했다.

기존 색인의 [SenseNova-U1.5-MoT](https://huggingface.co/sensenova/SenseNova-U1.5-8B-MoT)는 NEO-unify 기반 이미지 생성·편집 계열이다. Loop를 그 제품의 크기 변경이나 이미지 생성 후속 버전으로 설명하지 않는다. 기존 Dory·ALoDLM에 반복 연산 아이디어가 있다는 사실과 해당 가중치의 직접 파생은 다르며, 이번 공개 자료에서 그 두 checkpoint를 재사용했다는 근거는 확인하지 못했다.

### 학습 recipe와 실제 출시 학습은 구분

공개 TorchTitan 예제는 SFT·sigmoid DPO·MTP 경로를 제공하며, 기본값은 8 GPU·8K·동결 vision이다. 256K 옵션도 있으나 **packed sample 전체 길이가 단일 256K 문서 학습을 의미하지 않는다**고 원문이 경고한다. 예제 script의 100회 기본 iteration과 작은 합성 데이터를 실제 출시 모델의 학습량·품질 근거로 쓰지 않는다. [학습 문서의 범위와 한계](https://github.com/OpenSenseNova/torchtitan/blob/main/examples/train/SenseNova-Loop-9B-Preview/README.md).

### 활용 예: 문서 비교·도구 선택을 읽기 전용으로 시험

다음은 본 보고서가 제안하는 평가 시나리오이며 실행 결과가 아니다.

1. 직접 만든 짧은 문서 두 개에 서로 다른 날짜·금액을 넣고, 작은 도표 이미지를 곁들인다.
2. 질문: “두 자료의 충돌 항목을 찾아 문서명과 근거를 붙이세요. 없는 정보는 추정하지 말고 확인 불가로 표시하세요. 파일을 수정하거나 메시지를 보내지 마세요.”
3. 같은 자료로 이미지 포함/제외, 짧은 문맥/긴 문맥을 나누어 숫자 정확도·근거 일치·누락·응답 지연을 측정한다.
4. 도구를 연결할 때는 읽기 전용 검색부터 시작하고, 문서 안에 삽입된 명령문을 따르지 않는지도 시험한다. 최종 외부 행동은 별도 승인으로 분리한다.

[공식 실행 안내](https://github.com/OpenSenseNova/SenseNova-Loop#getting-started)는 custom implementation과 전용 환경을 요구하고, SGLang은 특정 지원 PR을 포함한 build를 안내한다. 일반 안정판에 모델 이름만 넣으면 전체 loop가 재현된다고 가정하지 않는다. remote code와 revision을 먼저 검토해야 한다. 공개 MTP와 아직 학습 중이라고 표시된 DSpark/DFlash2를 구분한다. **최소 VRAM·한국어 품질·긴 문맥 속도는 미확인**이다.

### 이용 조건·불확실성

[프로젝트 LICENSE](https://github.com/OpenSenseNova/SenseNova-Loop/blob/main/LICENSE)는 Apache-2.0 전문이다. 재배포 시 약관·고지·변경 표시 의무를 확인한다. HF 카드의 라이선스 표기와 프로젝트 원문은 확인했지만, HF 저장소의 별도 LICENSE/config 직접 조회는 도구 오류로 성공하지 못했다. 모델 파일 자체·정확한 tensor 수·정밀도별 용량은 독립 검증하지 않았다. 외부 라이브러리·학습 코드까지 모두 같은 라이선스라고 확대하지 않는다.

모델은 Preview이고 기술 보고서는 예고 상태다. 공식 성능 도표는 제작자 평가이며 독립 재현하지 않았다. 14.6B라는 실행 환산 표기를 14.6B개의 고유 저장 가중치 또는 특정 14.6B 모델과 동등 성능이라는 뜻으로 쓰지 않는다.

## 2. 제외·보류 기록

다음은 검토 기록이며 신규 소개 수·오늘 색인 추가 대상이 아니다.

- **[Pika-H3-Flex](https://huggingface.co/Pika-Labs/Pika-H3-Flex): 직접 파생 제외.** 공식 카드가 H3 후학습을 명시하고, 실행 예는 MiniMax-H3에 LoRA를 로드한다. 기존 MiniMax-H3의 별도 새 계열로 세지 않는다.
- **[MiniCPM-OCR-1.0](https://huggingface.co/openbmb/MiniCPM-OCR-1.0): 직접 작업 특화 파생 제외.** MiniCPM-V4.6 위 OCR 학습이라는 공식 설명에 따라 이전 제외 판단을 유지한다.
- **[MiniMax-M3.1-Flash](https://huggingface.co/MiniMaxAI/MiniMax-M3.1-Flash): 보류 유지.** M3 핵심 MoE 유지, 첫 세 attention 층 변경·QAT·DSpark는 확인했지만, 기존 M3와 별개 주요 세대로 등록할 충분한 비교 판단은 확정하지 않았다. HF 220B 표시와 공식 약 428B total/23B active도 혼동하지 않는다.
- **[Unlimited-OCR-2](https://huggingface.co/baidu/Unlimited-OCR-2): 보류 유지.** 공식 10/27 공개와 SR-SWA는 확인했으나 기존 R-SWA 세대와의 학습·구조 비교를 이번에 완료하지 않았다. “2”나 무제한 문서 홍보만으로 새 계열로 올리지 않는다.
- **[Idol](https://huggingface.co/speridlabs/idol): 계보 검증 보류.** [공식 SDK](https://github.com/speridlabs/idol-sdk)가 TripoSplat 기반임을 밝힌다. 기존 Iris와 출력 분야가 다르다는 것만으로 독립 신규성을 확정하지 않으며, TripoSplat/Idol 전체의 최초 소개 가능성은 충분한 계보 검증 전 보류한다.
- LFM3 modality/저정밀 배포, Mistral Large4, Nemotron Transcribe, MOSS-Image, WeVisOne, Hi3D, Hy-Nomas 및 이미 등록된 Qwen/DeepSeek 계열의 크기·양자화·포맷·직접 미세조정은 제외했다.

## 조사 범위·한계

HF 트렌딩 [1페이지](https://huggingface.co/models?sort=trending)·[2페이지](https://huggingface.co/models?p=1&sort=trending)·[3페이지](https://huggingface.co/models?p=2&sort=trending), 후보 공식 카드와 개발자 저장소를 확인했다. 페이지별 캐시·갱신 시차가 있어 동시 순위표로 해석하지 않는다. 동일 조건의 전주 snapshot이 없어 **정확한 좋아요·다운로드 증가율과 순위 변동은 미확인**이다. 일부 HF 본문·raw/config 조회 오류는 공식 검색 본문과 GitHub 원문으로 보완했고, 남은 불확실성은 위에 표시했다.

“오늘 새 모델은 하나뿐”이라는 전수 조사 주장이 아니다. 숫자를 채우지 않고 공개 자료로 판정한 범위만 기록했다. **가중치 다운로드·설치·모델 실행·benchmark 재현·GPU 측정은 하지 않았다.** 게시 검증과 모델 품질 검증을 구분한다.
