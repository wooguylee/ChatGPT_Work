## 1. Hy-Nomas: 카메라 조건을 받는 구간별 자기회귀 영상 생성

**태그:** world-model, interactive-video-generation, camera-control, segment-autoregressive, diffusion-transformer, KV-cache.

### 신규성: 단순 PixelUMM 미세조정과 다른 생성기

[공식 카드](https://huggingface.co/tencent/Hy-Nomas)는 **54개 dual-stream MMDiT 블록·hidden 2,048·16 heads**의 생성기를 설명한다. 영상은 32-channel DCAE-V 잠재공간에서 생성되고, text/video의 구간별 causal joint attention과 이전 구간 KV cache를 사용한다. 카메라 extrinsic은 별도의 cross-attention으로 주입된다.

[실제 모델 정의](https://github.com/Tencent-Hunyuan/Hy-Nomas/blob/911cea6458a89c2663513ff7099561ec190dd491/hymm/models/dit/modules/__init__.py)에서도 54 double/0 single blocks, latent 32 channels, camera injection과 전용 CPTHYNomasDiffusionTransformer를 확인했다. 단순 서비스 wrapper나 기존 checkpoint의 이름 변경만을 근거로 선정하지 않았다.

기존 [10/6 PixelUMM 보고서](2026-10-06.md)의 raw-pixel/shared-attention 통합 생성 백본과 달리, 이번 핵심은 **별도 latent MMDiT의 연속 세계 생성 경로**다. Qwen2.5-VL-7B는 text encoder로, 미세조정된 PixelUMM은 생성 잠재값을 영상으로 복원하는 decoder로 재사용된다. 기존 구성요소 자체를 신규 모델로 세지 않는다. **DiT의 최초 가중치 초기화와 전체 사전학습 자료·양은 미확인**이므로 모든 부분을 처음부터 학습했다거나 독립 가중치 계보가 입증됐다고 주장하지 않는다.

base·distilled·INT8·Diffusers 변환 및 cinematic/robotics LoRA는 모두 같은 Hy-Nomas 한 계열로 묶는다. 선정은 이처럼 확인된 **생성기 구조·입출력 경로의 실질적 차이**에 한정한다.

### 활용 예와 실행 조건

실무 시험 예: 0~5초에는 빈 전시장을 생성하고, 5~10초에는 “가운데 조형물을 추가하고 카메라를 오른쪽으로 이동”하도록 바꾼 뒤 객체 유지·시점 일관성을 확인한다. 이는 검증할 시나리오이며 성공을 보증하지 않는다.

[공식 실행 문서](https://github.com/Tencent-Hunyuan/Hy-Nomas#inference)에 따라 환경·가중치·구간별 prompt JSON을 먼저 준비한 뒤 실행하는 예다.

```bash
export Hy_Nomas_Model_Path=/path/to/Hy-Nomas
bash scripts/inference/inference_from_config.sh configs/experiment/inference.yaml \
  dit_weight="${Hy_Nomas_Model_Path}/DiT/distilled/diffusion_pytorch_model_ema_0_995.safetensors" \
  model.vae.checkpoint="${Hy_Nomas_Model_Path}/VAE/PixelUMM_FT/diffusion_pytorch_model.safetensors" \
  inference.prompt=/path/to/prompts.json \
  inference.save_path=./outputs/distill
```

[표준 설정](https://github.com/Tencent-Hunyuan/Hy-Nomas/blob/911cea6458a89c2663513ff7099561ec190dd491/configs/experiment/inference.yaml)은 8-way sequence parallel, 720×1280, 출력 24 FPS, DiT 8-step, PixelUMM decoder 1-step이다. **24 FPS는 재생 프레임률이지 실시간 생성 속도가 아니다.** 기본 full-history cache는 장시간 생성 시 메모리가 늘어난다.

별도의 [저메모리 실행](https://github.com/Tencent-Hunyuan/Hy-Nomas#inference-with-low-mem-gpu)은 RTX 4090 한 장을 대상으로 INT8 DiT/KV, FP8 decoder, 제한된 활성 history와 CPU offload를 결합한다. 기본 BF16·8-GPU 설정의 비용과 혼동하지 않으며 RAM·전송 비용을 고려해야 한다. interactive demo의 Nomas-PE 별도 서비스까지 한 GPU에서 모두 돌아간다는 뜻도 아니다. 일반 diffusers 안정판 호환성을 가정하지 않는다.

### 라이선스·평가 한계

[공식 LICENSE](https://github.com/Tencent-Hunyuan/Hy-Nomas/blob/main/LICENSE)는 Tencent가 공개한 Hy-Nomas 코드·parameters·weights의 Apache-2.0 적용과 외부 구성요소의 원래 약관 유지를 명시한다. 모델 카드도 같은 취지다. **PixelUMM·Qwen 등 포함 자산의 개별 이용 조건을 자동으로 Apache로 바꾸지 않는다.** 기존 PixelUMM 공개 가중치는 [10/6 확인 기록](2026-10-06.md)상 비상업 연구·평가 조건이었다. 이번 수정 decoder에 대한 별도 권리 부여까지 확인한 것은 아니므로, 전체 pipeline의 무제한 상업 이용을 보증하지 않는다. 재배포·상업 도입 전 실제 받는 자산의 원천 약관을 별도로 확인해야 한다.

Technical report는 공식 README에서 아직 예고 상태다. 오늘은 통제 가능성·물리 정확도·장기 기억의 독립 benchmark 수치를 주장하지 않는다. **설치·가중치 다운로드·모델 실행·GPU 측정은 하지 않았으며 예시는 문서 기반**이다.

## 2. 제외·보류 기록

아래는 검토 기록이며 신규 수·인덱스 추가 대상이 아니다.

- **[Kromoss](https://huggingface.co/lodestones/Kromoss): 직접 파생 제외.** lodestones, HF 약 5B, Apache-2.0. 카드가 MOSS-Image-Base full fine-tune이며 구조·text encoder·VAE·pipeline이 동일하다고 명시한다. 8-step DMD/DMD2 LoRA와 INT8도 별도 계열로 세지 않는다.
- **[Gradium Phonon](https://huggingface.co/gradium/phonon-31m-en): 보류.** Gradium, 대표 31M은 audio tokenizer 제외; 31m-en Apache-2.0, 40M 배포는 CC BY-NC 4.0으로 구분한다. Pocket TTS·Mimi 기반이라고 밝히므로 이미 등록된 Pocket TTS와의 주요 구조·학습 차이를 충분히 확정하기 전 신규로 등록하지 않는다. 이름이 유사한 기존 Phonon1/Fermion과 동일 계열이라고 단정한 것은 아니다.
- **[Sage-A1.5](https://huggingface.co/InternScience/Sage-A1.5): 직접 계보 보류.** Shanghai AI Laboratory/InternScience, 공식 35B MoE, Apache-2.0. Qwen3.6·Agents-A1 기반 orchestration·verification 기능은 확인했지만 기존 Agents-A1 계열을 넘어서는 명백한 구조·핵심 학습 변화가 이번 자료만으로 확정되지 않았다. 기능 홍보·자체 점수만으로 추가하지 않는다.
- **KittenTTS 2·OrcaCyber-Nano:** 트렌딩 노출은 확인했으나 카드 본문 열람 실패. 메타데이터·신규성을 추정하지 않는다.
- **MiniMax-M3.1·Granite Speech 5.0·OvisOCR3:** 이전 보고서의 계보 보류를 해제할 추가 비교 검증을 완료하지 않았다. 최신 번호만으로 새 계열로 세지 않는다.
- Flint·Raon-1 mini·Fibo2·MemT·OXR·Nemotron Parse·MOSS-Image 및 Qwen/DeepSeek의 GGUF·양자화·포맷·크기·미세조정 배포는 기존 계열로 제외한다.
