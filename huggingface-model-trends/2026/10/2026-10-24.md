## 1. OXR-1.0: 별도 사전학습한 문서 인식 계열

**태그:** OCR, document-parsing, image-to-text, reading-order, layout, Markdown, JSON, RSI.

### 신규성 근거

공식 저장소는 OXR를 **처음부터 사전학습**했다고 명시한다. 인덱스에 없던 계열이며 기존 Qwen·Nemotron·Ovis의 checkpoint 미세조정이라고 소개하는 것이 아니다. 다만 학습량·데이터 구성과 전체 내부 구조는 미확인이고 technical report는 예고 상태다.

시스템은 교체 가능한 layout model과 OXR로 나뉜다. OXR는 내용 인식과 읽기 순서를 함께 처리하며, 후학습에서는 오답·취약 샘플을 대상으로 RSI 반복을 사용한다고 설명한다. [공식 구조·학습 설명](https://github.com/SoMarkAI/OXR#how-it-works).

외부 코드도 사용한다. [NOTICE](https://github.com/SoMarkAI/OXR/blob/main/NOTICE)는 D-FINE 추론 adaptation과 XY-Cut++ 기반 후처리를 명시한다. 따라서 **전 구성요소를 독자 개발·사전학습했다는 뜻은 아니다**. 기존 layout 알고리즘을 다시 신규 모델로 세지 않는다.

### 활용 예와 실행 조건

공개 PDF의 표·본문을 Markdown/JSON으로 바꿔 RAG 입력을 준비하는 후보이다. 공식 환경과 모델을 준비하고 로컬 서비스를 띄운 뒤 사용하는 요청 예다.

```bash
curl --fail-with-body http://localhost:8000/v1/parse/sync \
  -F 'file=@sample.pdf' \
  -F 'api_key=dummy' \
  -F 'output_formats=markdown' \
  -F 'output_formats=json'
```

[공식 로컬 실행·요청 안내](https://github.com/SoMarkAI/OXR#quick-start)는 Linux·BF16 NVIDIA GPU·CUDA 13.0 호환 드라이버, 저동시성 시험 24GB·권장 48GB 이상을 제시한다. 일반 vLLM만으로 충분하지 않고 제공 plugin이 필요하다. 실행 전 코드·revision을 검토한다. 무료 외부 API 대신 localhost 예시를 사용했다.

실무 시험에서는 표의 병합 셀·숫자·각주·읽기 순서를 원본과 대조한다. 한국어 스캔·복잡한 세로쓰기·저품질 이미지의 성능은 이번에 검증하지 않았다. **설치·다운로드·모델 실행은 하지 않았으며 예시는 문서 기반**이다.

### 라이선스와 평가를 읽는 법

[코드 LICENSE](https://github.com/SoMarkAI/OXR/blob/main/LICENSE)는 Apache-2.0에 추가 제한이 붙은 **OXR License**다. 본인과 관계사의 연결 기준 누적 자금조달 또는 직전 회계연도 연매출 중 하나가 **USD 2M을 초과**하면 상업 이용에 별도 라이선스가 필요하다. 제3자 온라인 서비스에는 표시 의무가 있고, 경쟁 문서 파싱/OCR hosted API 제공은 자금·매출과 무관하게 별도 서면 허가를 요구한다. 일반 Apache-2.0·무제한 상업 이용이라고 요약하지 않는다.

특히 [NOTICE](https://github.com/SoMarkAI/OXR/blob/main/NOTICE)는 **가중치가 코드 배포에 포함되지 않고 조건은 모델 저장소에서 별도로 제공**된다고 명시한다. 코드 라이선스를 가중치에 자동 적용하지 않는다. 이번에는 가중치 약관을 독립 확인하지 못했으므로 실제 도입 전 해당 배포 조건 확인이 필요하다.

[제작자 benchmark 문서](https://github.com/SoMarkAI/OXR/blob/main/docs/benchmark.md)의 정확도 snapshot은 **10/5**이며 olmOCR-bench 87.84, OmniDocBench 97.18, DocParsingBench 87.76을 보고한다. 이는 제작자의 특정 비교표·protocol 결과이며 오늘의 보편적 1위나 독립 재현 결과가 아니다. 문서의 557.77 native tokens/s·0.990373 pages/s도 측정 조건에 한정한다. **10/5는 평가 snapshot이지 모델 출시일이 아니다.**
