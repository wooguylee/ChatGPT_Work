## 선정 모델
1. [meta-models/Muse-Glimmer-30B](https://huggingface.co/meta-models/Muse-Glimmer-30B) — Meta Superintelligence Lab. 약 30B 멀티모달 로컬 에이전트·코딩·도구 호출 모델로 공개 직후 빠른 커뮤니티 반응을 보임.
2. [IndexTeam/IndexTTS-2.5](https://huggingface.co/IndexTeam/IndexTTS-2.5) — IndexTeam/Bilibili. 약 0.8B zero-shot TTS·음성 복제·다국어 더빙.
3. [H-EmbodVis/SimWAM](https://huggingface.co/H-EmbodVis/SimWAM) — 자율주행 World Action Model. 영상 생성 지식을 행동 예측에 전달하고 추론 시 영상 생성부를 제거하는 접근.
4. [erikkaum/lattice-retrieval](https://huggingface.co/erikkaum/lattice-retrieval) — 약 31M 초경량 static retrieval. Transformer 없이 token vector 평균으로 초고속 1차 검색을 지향.
5. [bench-labs/AudioModel-v1](https://huggingface.co/bench-labs/AudioModel-v1) — Bench Labs. 약 40M Text-to-Audio 실험 모델.
