# Hugging Face 주목 모델 — 2026-08-26

> 기존 ChatGPT 대화에서 마이그레이션한 보고서입니다. 마이그레이션 시 Hugging Face의 최신 1차 출처와 충돌한 일부 수치/라이선스 표기는 확인 가능한 값으로 정정했습니다.

## 1. ibm-granite/granite-4.2-30b

- Hugging Face: https://huggingface.co/ibm-granite/granite-4.2-30b
- 개발: IBM Granite Team
- 분야/규모: Reasoning LLM / Coding / Tool Calling / Agent, 30B dense, native 128K context(확장 512K)
- 공개: 2026-08-25
- 주목 근거: Granite 4.2 세대가 3B/8B/30B로 공개되었고 reasoning, thinking mode, tool calling, agentic workflow를 핵심으로 전면에 내세움. 한국어가 공식 테스트 언어에 포함됨.
- 기술적 차이: thinking/non-thinking/low-effort thinking을 한 모델에서 선택할 수 있고, 8B/30B에는 실제 도구 환경을 활용한 agentic RL이 추가됨.
- 활용/제약: 사내 RAG Agent, 코딩 Agent, MCP/tool calling, 긴 문서 분석에 유망. 30B dense는 일반 PC에서 무거워 양자화 또는 3B/8B 계열이 현실적일 수 있음.
- 비고: IBM이 공개한 벤치마크와 학습 효과는 개발사 자체 평가로 취급함.

## 2. apodex/Apodex-1.1-mini

- Hugging Face: https://huggingface.co/apodex/Apodex-1.1-mini
- 개발: Apodex Team
- 분야/규모: Agentic LLM / Deep Research / Coding / 데이터 분석, 약 36B MoE, Qwen3.5-35B-A3B 계열 기반
- 주목 근거: 장기 연구 작업에서 검색·보고서 작성에 그치지 않고 파일, 데이터, 코드, 도구를 직접 다루는 end-to-end agent 실행을 강조하며 빠르게 관심을 모음.
- 기술적 차이: AgentOS와 비동기 Agent Team을 통해 작업을 분해하고 여러 하위 에이전트가 병렬 실행·상태 공유·오류 복구를 수행하도록 설계됨.
- 활용/제약: 조사→데이터 정리→코드 실행→결과 검증→보고서 생성 같은 복합 workflow에 적합. 이름은 mini지만 36B급이라 보급형 GPU에는 무거움.
- 비고: FrontierFinance/APEX-Agent 등 모델 카드의 성능 수치는 Apodex 자체 평가임.

## 3. tencent/WeMM-Embedding-9B

- Hugging Face: https://huggingface.co/tencent/WeMM-Embedding-9B
- 개발: Tencent
- 분야/규모: Multimodal Embedding / RAG, 9B, 4096차원 L2-normalized embedding
- 주목 근거: 텍스트, 이미지, 영상, 시각 문서, interleaved multimodal 입력을 하나의 embedding 공간으로 통합하는 신규 계열로 등장.
- 기술적 차이: Qwen3.5 기반 universal multimodal embedding이며 Matryoshka-style 축소 임베딩 활용을 염두에 둔 설계. 오디오 입력은 지원하지 않음.
- 활용/제약: 텍스트↔이미지↔영상↔PDF 검색을 하나의 RAG 인프라에서 처리하기 좋음. 공식 언어는 중국어/영어 중심이라 한국어 품질은 직접 검증이 필요함.
- 라이선스: Hugging Face 현재 표기는 `wemm-model-license`이며 Apache 2.0으로 간주하지 않음.
- 비고: MMEB-v2 등 비교 수치는 Tencent 자체 기술자료의 평가로 취급함.

## 4. ibm-granite/granite-speech-5.0-470m-turboctc

- Hugging Face: https://huggingface.co/ibm-granite/granite-speech-5.0-470m-turboctc
- 개발: IBM Granite Speech Team
- 분야/규모: 영어 Automatic Speech Recognition, 470M
- 공개: 2026-08-25
- 주목 근거: Conformer+CTC 기반의 경량 encoder-only ASR로, 단일 H200 배치 조건에서 12,600 RTFx 이상을 IBM/Hugging Face가 공식 보고함.
- 기술적 차이: 이전 Granite Speech의 LLM backbone 대신 16-layer Conformer와 CTC greedy decoding을 사용하고 시간축을 크게 다운샘플링해 속도를 우선함.
- 활용/제약: 영어 회의 녹취, 콜센터 대량 STT, 실시간 자막, 노트북/스마트폰/WebGPU 실험에 적합. 영어 전용이라 한국어 STT에는 부적합함.
- 비고: WER/RTFx 수치는 지정 하드웨어와 공식 평가 조건의 결과이며 일반 PC 성능으로 해석하면 안 됨.

## 5. fastino/gliner2.5-multi-v1

- Hugging Face: https://huggingface.co/fastino/gliner2.5-multi-v1
- 개발: Fastino
- 분야/규모: Information Extraction / NER / Classification / Relation Extraction, 약 0.3B multilingual
- 주목 근거: GLiNER2.5 계열이 Token Classification/Information Extraction 관련 트렌딩 상위에 진입. 소형 모델로 엔터티, 분류, 구조화 레코드, 관계, span attribute를 하나의 schema-driven interface로 처리함.
- 기술적 차이: 고정 span-width enumeration 대신 sparse start/end boundary architecture를 사용해 긴 span과 긴 문서 처리의 계산 비효율을 줄임.
- 활용/제약: OCR 텍스트에서 회사명·금액·날짜·주소를 JSON으로 추출하거나 계약서 조항/PII 탐지/문의 분류에 유용. CPU/CUDA/MPS 로컬 추론이 가능하지만 한국어 개별 정확도는 별도 검증이 필요함.
- 비고: Fastino가 공개한 벤치마크는 개발사 자체 평가임.
