## 1. building-pydantic-ai-agents
- 기본 정보: Pydantic · https://www.skills.sh/pydantic/skills/building-pydantic-ai-agents · https://github.com/pydantic/skills · Codex/Claude Code/Cursor/Copilot 등 Agent Skills 호스트.
- 지표: Hot #28, 표시값 14+14, 4.6K installs, GitHub 138★/4 forks, 66 commits, 최근 확인 활동 2026-09-19, Gen Agent Trust Hub/Socket/Snyk 모두 Pass. 24h 증가·좋아요·품질점수는 미확인.
- 설명: tool, structured output, streaming, delegation, testing, lifecycle hook, context gating, Logfire observability를 production Agent 구조로 묶는다. Pydantic type model과 tool schema를 연결해 입력/출력 계약을 명확하게 만든다.
- 설치: `npx skills add https://github.com/pydantic/skills --skill building-pydantic-ai-agents`. Python/Pydantic AI 및 모델 provider API Key가 추가로 필요할 수 있다.
- 활용 예시: Pydantic 모델로 tool 입출력을 제한하고 streaming·테스트·재시도 경계·Logfire 관측 지점까지 갖춘 Agent를 만들어줘.
- 평가: 타입 안정성과 테스트/관측을 함께 다뤄 실무 가치가 높다. Python 중심이라는 제약이 있다.

## 2. gws-gmail-triage
- 기본 정보: googleworkspace · https://www.skills.sh/googleworkspace/cli/gws-gmail-triage · https://github.com/googleworkspace/cli · Codex/Claude Code/Cursor/Copilot 등.
- 지표: Hot #162, 표시값 9+5, 43.5K installs, 31.1K★/1.9K forks, 283 commits, Gen Agent Trust Hub Pass/Socket Pass/Snyk Warn. 24h 증가·좋아요·품질점수는 미확인.
- 설명: `gws gmail +triage`로 unread Gmail을 sender/subject/date 중심으로 읽기 전용 분류하고 JSON 결과를 Agent workflow에 연결한다. Google Workspace CLI의 Discovery 기반 API surface를 이용한다.
- 설치: `npx skills add https://github.com/googleworkspace/cli --skill gws-gmail-triage`; CLI는 `npm install -g @googleworkspace/cli`, 이후 Google OAuth 설정이 필요하다.
- 활용 예시: 최근 48시간 unread 메일만 읽기 전용으로 확인해 답장 필요/정보성/자동 알림으로 분류해줘.
- 평가: 최소 권한 triage에 적합하지만 현재 Snyk Warn과 OAuth scope를 확인해야 한다.

## 4. cmux-cloud-vm
- 기본 정보: Manaflow · SkillsMP https://skillsmp.com/creators/manaflow-ai/cmux/skills-cmux-cloud-vm · GitHub https://github.com/manaflow-ai/cmux · Codex/Claude Code/OpenCode/Pi 등 CLI Agent.
- 지표: SkillsMP 27,306★/2,386 forks, live GitHub 27.4K★/2.4K forks, 17,761 commits, 2026-09-26에도 commit 확인. installs·좋아요·품질·보안점수는 미확인.
- 설명: `cmux vm route/run/agent/tree`와 terminal persistence를 이용해 Agent 작업을 persistent cloud VM으로 라우팅한다. workspace, browser/VNC, file/env transfer, checkpoint/fork까지 Agent 실행 인프라로 묶는다.
- 설치: `npx skills add https://github.com/manaflow-ai/cmux --skill cmux-cloud-vm`; host는 현재 macOS 중심이며 cmux 앱/로그인이 필요하다.
- 활용 예시: 기존 cloud machine의 별도 workspace에서 Codex를 detached로 실행해 전체 테스트를 돌리고 종료 코드와 실패 항목만 가져와줘.
- 평가: Agent 실행 장소 자체를 Skill로 추상화한 점이 독창적이다. macOS 중심 host 제약이 있다.

## 5. notcrawl
- 기본 정보: OpenClaw · AgentSkill.sh https://agentskill.sh/@openclaw/notcrawl · 실행 도구 https://github.com/openclaw/notcrawl · Codex/Claude Code/Cursor/OpenCode 등.
- 지표: Security 100/100, 4.7/5(3), updated 2026-09-25. 실제 tool repo 133★/17 forks, 252 commits, 최근 활동 2026-09-25. installs·24h 증가·품질점수는 미확인.
- 설명: Notion 데이터를 local SQLite+normalized Markdown으로 미러링해 FTS5 검색, read-only SQL, export, git snapshot을 제공한다. Desktop cache, 공식 Notion API, Codex Notion connector targeted repair 경로를 지원한다.
- 설치: AgentSkill.sh `/learn @openclaw/notcrawl`; 실행 도구는 `brew install openclaw/tap/notcrawl`. API sync에는 Notion access token이 필요하다.
- 활용 예시: archive freshness를 확인한 뒤 최근 30일 API migration 관련 Notion 문서의 제목·날짜·핵심 결정만 정리해줘.
- 평가: 별도 RAG 구축 없이 기존 지식을 Agent memory로 만드는 방식이 실용적이다. initial sync와 권한 설정이 필요하다.

## 6. figma-use-motion
- 기본 정보: Figma/OpenAI plugin catalog · https://github.com/openai/plugins/blob/main/plugins/figma/skills/figma-use-motion/SKILL.md · upstream https://github.com/figma/mcp-server-guide/blob/main/skills/figma-use-motion/SKILL.md · 공식 배포는 Codex/ChatGPT plugin 중심.
- 지표: openai/plugins 7.2K★/927 forks, 306 commits, Figma plugin v2.0.20, repo update snapshot 2026-09-24. 개별 installs·좋아요·품질·보안점수는 미확인.
- 설명: `manualKeyframeTracks`, animation styles, easing, timeline duration으로 Figma motion을 편집하며 필요 시 export_video 후 ffmpeg로 핵심 frame을 sampling해 검증한다.
- 설치: Codex `/plugins`에서 Figma 연결. 별도 marketplace는 `codex plugin marketplace add openai/plugins`. `figma-use`와 함께 로드하며 motion API에는 metronome feature flag가 필요하다.
- 활용 예시: 카드 3개를 120ms 간격으로 fade-in/slide-up시키고 1.2초 timeline으로 맞춘 뒤 작은 video export 1회로 시작/중간/정착 frame을 검증해줘.
- 평가: 디자인 Agent가 시간축까지 직접 다루게 하는 발전된 Skill이다. 계정 feature flag가 없으면 사용할 수 없다.
