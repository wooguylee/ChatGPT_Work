## 1. vercel-composition-patterns

- **출처:** [skills.sh](https://www.skills.sh/vercel-labs/agent-skills/vercel-composition-patterns)
- **GitHub:** [vercel-labs/agent-skills](https://github.com/vercel-labs/agent-skills)
- **제작자/조직:** Vercel Labs
- **지원 Agent:** skills.sh가 Claude Code, Cursor, Codex, GitHub Copilot, Windsurf, Gemini, Cline, AMP, Antigravity, OpenClaw 등을 지원 대상으로 제공한다.
- **인기/트렌드 snapshot:** skills.sh 24h Trending **#220**, 약 **+2.3K/24h**. 개별 페이지 기준 약 **353.3K installs**. GitHub API 기준 **31,491 stars / 2,762 forks**. 저장소 최근 push는 **2026-08-28 22:36 KST**. Gen Agent Trust Hub / Socket / Snyk 감사 모두 **Pass**.

### 무엇을 하는가
React 컴포넌트가 `isCompact`, `isMobile`, `showHeader` 같은 boolean prop 조합으로 폭발하는 문제를 composition으로 푼다. Compound component, context provider, state lifting, explicit variant 같은 구조를 Agent가 선택하도록 규칙과 예시를 제공하며, React 19의 `use()`와 `forwardRef` 변화까지 포함한다. 단순 스타일 가이드보다 **컴포넌트 API 구조 자체를 바꾸는 refactoring 규칙집**에 가깝다.

### 설치 및 사용
```bash
npx skills add https://github.com/vercel-labs/agent-skills --skill vercel-composition-patterns
```

추가 MCP/API Key는 필요 없다. Node.js/npm과 해당 Agent의 Skill 지원만 있으면 된다.

**예시 명령:**
> `src/components/DataTable.tsx의 boolean prop이 너무 많아. vercel-composition-patterns 기준으로 compound component 구조로 리팩터링하고 기존 public API 호환성 위험도 같이 설명해줘.`

**평가:** 이미 설치 기반이 큰데도 24시간 증가가 계속 보인다는 점이 강하다. 다만 React 중심 Skill이라 백엔드·비 React 프로젝트에는 직접 가치가 낮다.

### 무엇을 하는가
Cloudflare의 Workers, R2, D1, KV, Durable Objects, Vectorize, Agents SDK, Tunnel, WAF 등 50개 이상의 제품을 그냥 나열하지 않고 **요구사항 → 제품 선택** decision tree로 연결한다. 특히 가격·제한·API signature처럼 쉽게 낡는 정보는 모델의 사전지식보다 최신 Cloudflare 문서를 확인하도록 강제한다. Agent가 먼저 아키텍처를 고르고 필요한 세부 Skill/문서로 내려가는 라우터 역할을 한다.

### 설치 및 사용
```bash
npx skills add https://github.com/cloudflare/skills --skill cloudflare
```

Skill 자체에는 별도 키가 필요 없지만 실제 배포/계정 조작에는 Cloudflare 인증이 필요하다. Wrangler나 Cloudflare MCP를 함께 쓰면 실행 단계까지 확장할 수 있다.

**예시 명령:**
> `Node.js API에서 업로드 파일, 비동기 작업, 벡터 검색이 필요해. cloudflare Skill의 decision tree로 Workers/R2/Queues/Vectorize 조합을 선택하고 최소 구성을 만들어줘.`

**평가:** 특정 제품 문법을 암기시키는 대신 최신 문서 조회와 제품 선택을 분리한 구조가 좋다. Cloudflare를 쓰지 않는 프로젝트에는 범용성이 낮다.

## 3. qwen-mm-plugins-api

- **출처:** [SkillsMP](https://skillsmp.com/creators/qwenlm/qwen-mm-plugins/src-capabilities-api-skill)
- **GitHub:** [QwenLM/Qwen-MM-Plugins](https://github.com/QwenLM/Qwen-MM-Plugins)
- **제작자/조직:** QwenLM
- **지원 Agent:** SkillsMP가 Codex/Claude 등에 설치 가능한 Agent Skill로 제공하며, 기능 실행은 Qwen-MM MCP 도구를 전제로 한다.
- **인기/트렌드 snapshot:** SkillsMP가 확인한 2026-09-17 source snapshot은 **2,952 stars / 187 forks**. GitHub API의 현재 값은 **2,975 stars / 189 forks**, 저장소 최근 push는 **2026-09-23 19:44 KST**. SkillsMP에서 공개 24h 설치 증가/랭킹/좋아요/품질·보안 점수는 확인되지 않았다.

### 무엇을 하는가
이미지·영상·오디오 작업을 하나의 멀티모달 Agent 도구층으로 묶는다. Qwen-VL은 VQA/OCR/공간 grounding, Qwen-Omni는 영상 프레임+오디오를 함께 보고 ASR·화자 분리·시간 구간 grounding·이벤트 counting·음악 caption을 처리하며, 별도 Qwen3-ASR과 SAM3 segmentation도 연결한다. 핵심은 Agent가 파일을 단순히 '읽는' 수준을 넘어 **WHERE(공간), WHEN(시간), WHO(화자), WHAT(내용)**을 적절한 MCP 도구로 라우팅한다는 점이다.

### 설치 및 사용
```bash
npx skills add https://github.com/QwenLM/Qwen-MM-Plugins --skill qwen-mm-plugins-api
```

실제 호출에는 Qwen-MM MCP 서비스 설정이 필요하다. 기본 hosted 경로는 `DASHSCOPE_API_KEY`를 사용할 수 있고, OpenRouter/OrcaRouter 또는 OpenAI-compatible/self-hosted endpoint도 가능하다. `transcribe_audio`의 로컬 미디어 처리에는 **FFmpeg**가 필요하며, segmentation은 **SAM3 server (`SAM3_SERVER_URL`)**가 필요하다.

**예시 명령:**
> `meeting.mp4에서 화자별 발언을 timestamped SRT로 만들고, 화면에 오류 팝업이 등장한 시간 구간을 찾아 해당 프레임의 텍스트도 OCR해줘.`

**평가:** 멀티모달 Agent가 단일 VLM 호출에서 여러 전문 도구를 조합하는 방향을 잘 보여준다. 대신 API Key, MCP 서비스, FFmpeg/SAM3 등 준비 비용이 가장 크다.

### 설치 및 사용
```bash
npx skills add https://github.com/CodeAlive-AI/ai-driven-development --skill mcp-management
```

Skill 설치 자체는 Node.js/npm 정도면 충분하다. 실제 MCP 서버에 따라 OAuth/API Key가 필요할 수 있으며, 추가·삭제·인증 변경 후에는 해당 Agent를 재시작해야 하는 경우가 있다.

**예시 명령:**
> `이 프로젝트에 GitHub와 PostgreSQL MCP를 Codex와 OpenCode 둘 다에서 쓰게 설치해줘. 프로젝트 범위 설정을 우선하고 인증 정보는 파일에 하드코딩하지 마.`

**평가:** 여러 Agent를 동시에 쓰는 개발자에게 즉시 효용이 큰 운영형 Skill이다. 다만 각 Agent의 MCP 설정 형식이 자주 바뀌므로 Skill 업데이트 상태를 계속 확인해야 한다.

- **제작자/조직:** OpenAI
- **지원 Agent:** Agent Skills 형식을 읽는 Codex/Claude Code 계열 환경에서 설치 가능. SkillsMP도 Codex/Claude용 설치 명령을 제공한다.

### 무엇을 하는가
코드에서 사용자에게 노출되는 export, 설정, 환경변수, CLI, default behavior를 먼저 inventory한 뒤 현재 `docs/`와 역방향으로 대조해 누락·오류·구조 문제를 찾는다. 즉 “코드 변경 후 문서 한두 줄 고치기”가 아니라 **doc-first + code-first 두 방향 audit**를 수행한다. OpenAI Agents Python 저장소 버전은 생성된 번역 문서를 건드리지 않고, 변경 수준에 맞는 검증 tier와 `make build-docs` 실행까지 연결한다.

### 설치 및 사용
```bash
npx skills add https://github.com/openai/openai-agents-python --skill docs-sync
```

특별한 API Key는 필요 없다. 실제 대상 저장소의 Git history와 문서 빌드 도구는 사용 가능해야 하며, 프로젝트별 AGENTS.md/검증 규칙을 따른다.

**예시 명령:**
> `이번 브랜치에서 main 대비 추가된 환경변수와 public API를 찾아 docs/에 누락되거나 오래된 설명이 있는지 docs-sync 방식으로 감사하고, 수정이 필요한 파일과 근거를 표로 정리해줘.`

**평가:** Agent가 코드는 고치지만 문서를 놓치는 문제를 구조적으로 줄이는 유지보수 Skill이다. OpenAI 저장소 규칙에 맞춰 작성돼 있어 다른 프로젝트에서는 경로·빌드 명령을 그대로 적용하지 말고 현지화해야 한다.
