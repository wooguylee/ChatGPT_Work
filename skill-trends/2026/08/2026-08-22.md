## 1. momentic-explore-prompt

- **출처:** skills.sh
- **GitHub:** https://github.com/momentic-ai/skills
- **당시 지표:** Hot #8, 누적 약 10.3K installs, GitHub 약 13★, 주요 감사 Pass.

일반적인 Playwright 명령 모음이 아니라, 변경된 Git diff와 실제 웹앱을 AI가 탐색해 사용자 흐름 변화와 테스트 후보를 찾게 하는 Skill입니다. E2E 테스트를 개발자가 하나씩 명시하기보다 Agent가 화면을 돌아다니며 놓친 흐름을 찾는 데 초점이 있습니다.

### 설치

```bash
npx skills add https://github.com/momentic-ai/skills --skill momentic-explore-prompt
```

**활용 예:** "현재 git diff 기준으로 로그인/회원정보 화면의 달라진 사용자 여정을 탐색하고 Momentic 테스트 후보를 만들어."

**왜 볼 가치가 있었나:** AI가 만든 UI를 다른 AI가 실제 브라우저에서 탐색·검증하는 흐름을 잘 보여줌.

## 2. ai-research-explore

- **출처:** skills.sh
- **GitHub:** https://github.com/lllllllama/rigorpilot-skills
- **당시 지표:** Trending #18, 24h 약 9.2K, 누적 약 311K, repo 약 472★. 당시 일부 보안 검사 Warn.

딥러닝 연구 아이디어를 낼 때 기존 연구 비교, 재현 가능성, 공정한 baseline, ablation, novelty 검증을 거치게 하는 Skill입니다. 단순히 새로운 아이디어를 그럴듯하게 생성하는 대신 "정말 새롭고 검증 가능한가"를 먼저 확인합니다.

### 설치

```bash
npx skills add https://github.com/lllllllama/rigorpilot-skills --skill ai-research-explore
```

**활용 예:** "한국어 숫자 인식에 특화된 소형 음성모델 아이디어를 기존 연구와 비교하고 검증 실험까지 설계해."

**왜 볼 가치가 있었나:** Agent가 코딩 보조를 넘어 연구 방법론 자체를 따라가는 방향을 보여줌.

## 3. security-scan

- **출처:** SkillsMP / OpenAI Codex Security
- **GitHub:** https://github.com/openai/codex-security
- **당시 지표:** repo 약 9,873★ / 693 forks, 2026-08-15 전후 활발한 업데이트.

저장소 전체를 대상으로 범위 결정 → Threat Model → 파일 검토 → 취약점 후보 수집 → 검증 → Attack Path 분석 → 보고서/SARIF 생성까지 이어지는 보안 감사 Skill입니다. 단순 OWASP 체크리스트보다 실제 공격 경로와 도달 가능성을 평가하는 점이 핵심입니다.

### 사용 예

```bash
npm install @openai/codex-security
npx codex-security login
npx codex-security scan .
```

**활용 예:** "이 Node.js API 저장소 전체를 감사하고 실제 공격 가능한 경로가 있는 취약점만 우선순위로 정리해."

**왜 볼 가치가 있었나:** LLM 보안 리뷰를 체계적인 Threat Model + Validation + Attack Path 단계로 나눔.

## 4. graphify

- **출처:** SkillsMP
- **GitHub:** https://github.com/Graphify-Labs/graphify
- **당시 지표:** repo 약 108.7K★, Skill installs 약 5.3K.

프로젝트 전체를 매번 Context에 넣기보다 소스 코드, 문서, SQL, PDF 등의 개체와 관계를 Knowledge Graph로 변환합니다. 결과를 `graph.json`, 보고서, 시각화 등으로 남겨 Codex가 필요한 관계만 조회하도록 하는 구조입니다.

### Windows/Codex 사용 예

```powershell
winget install astral-sh.uv
uv tool install graphifyy
graphify install --project --platform codex
graphify .
```

**활용 예:** "로그인 요청이 frontend부터 API, DB까지 어떤 파일과 모듈을 통과하는지 그래프로 추적해."

**왜 볼 가치가 있었나:** 대형 코드베이스에서 Agent의 Context 비용과 탐색 시간을 줄일 수 있는 접근.

## 6. smithery-ai-cli

- **출처:** Smithery
- **GitHub:** https://github.com/smithery-ai/cli
- **당시 지표:** 약 1,652 installs, repo 약 508★로 표기.

Codex가 필요한 MCP 서버를 검색하고 연결한 뒤 tool schema를 확인하고 호출할 수 있게 하는 CLI/Skill입니다. Skill과 MCP를 하나의 탐색·연결 흐름에서 다루는 것이 특징입니다.

### 설치/사용

```bash
npm install -g @smithery/cli
smithery auth login
smithery mcp search "github"
smithery mcp add "https://github.run.tools" --id github
smithery tool list github
```

Skill 설치:

```bash
npx skills add smithery-ai/cli
```

**활용 예:** "PostgreSQL을 관리할 수 있는 MCP를 찾아 제공 tool을 조사하고 연결 방법을 정리해."

**왜 볼 가치가 있었나:** Skill은 작업 방법, MCP는 실제 도구라는 구분을 실무적으로 연결하는 프로젝트.
