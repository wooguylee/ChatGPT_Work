## 1. nx-workspace

- **출처:** skills.sh
- **GitHub:** https://github.com/nrwl/nx
- **당시 지표:** Hot #1, Skill installs 약 233, Nx 저장소 약 29.2K★, 주요 감사 Pass.

Nx 모노레포에서 Agent가 무작정 파일을 탐색하지 않고 `nx show projects`, target, dependency 등의 구조 정보를 먼저 읽게 하는 Skill입니다. 대형 모노레포에서 작업 범위와 의존성을 안전하게 파악하는 read-oriented 접근이 특징입니다.

### 설치

```bash
npx skills add https://github.com/nrwl/nx --skill nx-workspace
```

**활용 예:** "이 Nx 프로젝트에서 front 앱이 어떤 shared library에 의존하는지 먼저 조사하고 변경 범위를 정해."

**왜 볼 가치가 있었나:** Agent가 대형 모노레포를 파일 검색보다 프로젝트 메타데이터 중심으로 이해하게 함.

## 2. github-issues

- **출처:** skills.sh
- **GitHub:** https://github.com/github/awesome-copilot
- **당시 지표:** Hot #7, 누적 약 14.9K installs, repo 약 38.1K★. 일부 보안 검사 Warn.

GitHub MCP와 `gh api`를 이용해 Issue 생성·조회·수정뿐 아니라 label, assignee, milestone, sub-issue, blocked-by, GitHub Project 관계까지 다루는 Skill입니다. 코딩 이후의 프로젝트 운영을 Agent 워크플로로 확장하는 데 초점이 있습니다.

### 설치

```bash
npx skills add https://github.com/github/awesome-copilot --skill github-issues
```

**활용 예:** "현재 버그들을 GitHub Issue로 만들고 frontend/backend로 라벨링한 뒤 선행 작업 관계까지 설정해."

**왜 볼 가치가 있었나:** Agent 개발이 코드 생성에서 Issue → 작업분해 → 의존관계 관리로 확장되는 사례.

## 3. duck-critic

- **출처:** SkillsMP
- **GitHub:** https://github.com/aktsmm/Agent-Skills
- **당시 지표:** 2026-08-09 소스 활동, repo 24★ / 4 forks.

주 모델(Producer)이 계획이나 코드를 만들고, 다른 계열 모델(Critic)이 읽기 전용으로 검토한 뒤 Producer가 수정하는 구조입니다. Critic은 코드를 직접 고치지 않고 오류·설계 문제를 지적하는 역할만 맡습니다.

### 설치

```bash
npx skills add https://github.com/aktsmm/Agent-Skills --skill duck-critic
```

**활용 예:** "인증 시스템 설계를 작성하되 중요한 결정마다 다른 모델에게 critic review를 받고 PASS할 때까지 수정해."

**왜 볼 가치가 있었나:** 여러 Agent가 모두 수정 권한을 갖는 대신 생산자와 검증자를 분리하는 패턴이 명확함.

## 5. cli-anything

- **출처:** AgentSkill.sh
- **GitHub:** https://github.com/HKUDS/CLI-Anything
- **당시 지표:** Security 100/100, Rating 5.0, repo 약 43K★.

GUI 프로그램의 소스와 기능을 분석한 뒤 Agent가 사용하기 좋은 CLI와 JSON 출력, 테스트, SKILL.md를 생성하는 프로젝트입니다. GIMP, Blender, Inkscape, OBS, FreeCAD 등 다양한 GUI 앱을 화면 클릭 대신 안정적인 CLI로 제어하려는 접근입니다.

### 사용 개념

```text
GUI 프로그램
  → 기능 분석
  → Agent용 CLI
  → JSON 출력
  → 테스트
  → SKILL.md
  → Codex 자동화
```

**활용 예:** "이 오픈소스 GUI 프로그램의 주요 기능을 Codex가 CLI로 조작할 수 있게 harness를 만들어."

**왜 볼 가치가 있었나:** UI automation의 불안정한 화면 인식 대신 프로그램 기능 자체를 Agent-friendly API처럼 변환.

### 설치

```bash
npx skills add https://github.com/openai/skills --skill security-threat-model
```

**활용 예:** "Node.js API의 Internet → CloudFront → API → PostgreSQL 흐름을 threat model해서 공격 경로를 정리해."

**왜 볼 가치가 있었나:** 체크리스트가 아니라 실제 코드와 데이터 흐름에 근거한 보안 설계를 유도.
