## 1. ai-video-generation

- **출처:** skills.sh
- **GitHub:** https://github.com/skills-101/superpowers
- **당시 인기 지표:** skills.sh 24시간 Trending #1, 24시간 약 21.9K, 누적 약 251.6K 설치. 저장소 Star 수와 설치 수 차이가 컸으며 일부 보안 검사 경고가 표시됨.

Codex/Claude가 직접 영상 모델을 돌리는 Skill이 아니라 `inference.sh` 계열 CLI를 통해 Veo 등을 포함한 여러 영상 생성 모델을 호출하도록 안내하는 Skill입니다. 핵심은 사용자의 영상 생성 의도를 모델/CLI 호출로 연결하는 것입니다.

### 설치/사용

```bash
npx skills add https://github.com/skills-101/superpowers --skill ai-video-generation
```

예시:

```bash
belt app run google/veo-3-1-fast \
  --input '{"prompt":"drone shot flying over a forest"}'
```

**활용 예:** "제품 소개용 10초 영상을 만들어줘"라고 요청하면 Agent가 모델 선택, 프롬프트 구성, 생성 호출을 이어서 수행.

**오늘 볼 가치:** 영상 생성 Skill의 급상승 자체가 멀티모달 Agent 도구 수요를 보여줌. 외부 CLI/서비스 의존성과 보안 검토는 필요.
