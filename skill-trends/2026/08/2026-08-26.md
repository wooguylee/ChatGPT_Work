## 1. grill-me

- **출처:** skills.sh
- **GitHub:** https://github.com/mattpocock/skills
- **당시 지표:** Trending #13, 24시간 약 11.0K 설치, 누적 약 964K, repo 약 235K★, 주요 감사 Pass.

Codex가 사용자의 설계를 그대로 받아 구현하지 않고 결정되지 않은 부분, 모순, 위험한 가정을 질문으로 파고드는 Skill입니다. 코드베이스를 읽어서 스스로 답할 수 있는 것은 직접 조사하고, 사용자만 결정할 수 있는 부분을 하나씩 묻는 방식이 특징입니다.

### 설치

```bash
npx skills add https://github.com/mattpocock/skills --skill grill-me
```

**활용 예:** "새 파일관리 프로그램 아키텍처를 grill-me로 검증해. 아직 구현하지 말고 빠진 설계 결정사항을 전부 찾아."

**왜 볼 가치가 있었나:** 별도 도구 없이 거의 모든 개발 프로젝트에 적용할 수 있고, 빠른 잘못된 구현을 막는 데 효과적.

## 3. entry-docs

- **출처:** SkillsMP
- **GitHub:** https://github.com/plimeor/agent-skills
- **당시 지표:** 2026-08-18 소스 업데이트, repo 약 3★. 신생 발굴형 Skill.

`README.md`는 사람이 프로젝트를 이해하는 문서, `AGENTS.md`는 Agent가 반복해서 읽는 운영 규칙이라는 역할 차이를 명확하게 정리하는 Skill입니다. 비대한 AGENTS.md가 매 요청마다 Context를 낭비하는 문제를 찾아 progressive disclosure 방식으로 세부 지침을 다른 문서로 분리합니다.

### 설치

```bash
npx skills add https://github.com/plimeor/agent-skills --skill entry-docs
```

**활용 예:** "이 저장소의 700줄 AGENTS.md를 분석해 매 요청마다 필요한 규칙만 남기고 나머지는 링크된 세부 문서로 분리해."

## 6. plugin-creator

- **출처:** ClaudeSkills.info / OpenAI Codex 공식
- **GitHub:** https://github.com/openai/codex
- **당시 지표:** Skill 설치 자체는 초기 단계였지만 OpenAI Codex repo는 매우 큰 규모였고 주요 감사 Pass.

개별 `SKILL.md` 하나를 만드는 대신 여러 Skill, MCP, Hook, Script, asset 등을 하나의 Codex Plugin 구조로 패키징하도록 돕는 Skill입니다. plugin manifest, marketplace 등록, validation 등 배포·재사용 단위까지 다룹니다.

개념 구조:

```text
my-plugin/
├─ .codex-plugin/
│  └─ plugin.json
├─ skills/
├─ hooks/
├─ scripts/
├─ assets/
├─ mcp/
└─ apps/
```

### 설치

```bash
npx skills add https://github.com/openai/codex --skill plugin-creator
```

**활용 예:** "내가 자주 쓰는 PostgreSQL 관리 Skill, AWS Skill, 코드 리뷰 Hook, 내부 MCP를 `my-company-devtools`라는 Codex Plugin으로 묶어."

**왜 볼 가치가 있었나:** Codex 확장 단위가 개별 Skill에서 재사용 가능한 Plugin 패키지로 올라가는 흐름을 보여줌.
